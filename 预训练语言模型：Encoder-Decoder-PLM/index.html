# T5 模型架构设计

T5（Text-to-Text Transfer Transformer）采用了 Encoder-Decoder 结构，其中编码器和解码器都基于 Transformer 架构设计。这种设计使得 T5 能够处理各种自然语言处理任务。

Encoder-Decoder架构详解

Encoder-Decoder 架构是一种序列到序列的神经网络架构，最初在机器翻译任务中广泛应用。编码器负责将输入序列编码为固定长度的向量表示，解码器则基于这个表示生成输出序列。在 T5 中，编码器处理输入文本，解码器生成目标文本，实现了真正的 "文本到文本" 转换。

T5 模型的整体结构包括两个主要部分：

  1. Tokenizer 部分：负责将文本转换为模型可处理的 token 序列
  2. Transformer 部分：包含编码器和解码器的核心计算模块

T5 的核心设计理念是将所有 NLP 任务统一为文本到文本的转换问题，这种统一性使得同一个模型可以处理翻译、摘要、问答等多种任务。

# 模型核心组件

# Self-Attention 与前馈网络

T5 模型的 Encoder 和 Decoder 部分都基于 Transformer 架构，主要包括两种核心结构：

  1. Self-Attention 机制：允许模型在处理序列中的每个位置时，关注序列中的所有其他位置
  2. 前馈神经网络：对注意力机制的输出进行进一步的非线性变换
Self-Attention机制原理

Self-Attention 机制通过计算查询（Query）、键（Key）和值（Value）之间的相似度来确定注意力权重。对于输入序列中的每个位置，模型可以关注到序列中的任何其他位置，这使得模型能够捕获长距离依赖关系。在 T5 中，编码器使用双向注意力，而解码器使用掩码注意力以保持自回归特性。

# RMSNorm 归一化技术

T5 模型的 LayerNorm 采用了 RMSNorm（Root Mean Square Normalization），这是一种改进的归一化方法。

RMSNorm 通过计算每个神经元的均方根来归一化每个隐藏层的激活值：

其中：

  • xxx 是输入向量
  • nnn 是向量维度
  • ϵ\epsilonϵ 是防止除零的小常数
  • γ\gammaγ 是可学习的缩放参数
RMSNorm相比LayerNorm的优势

与传统的 Layer Normalization 相比，RMSNorm 的参数设置更简单，只有一个可学习参数γ\gammaγ，去除了偏置项。这种简化不仅减少了计算开销，还能更好地适应不同的任务和数据集。实验表明，RMSNorm 在保持性能的同时提供了更好的训练稳定性。

# 预训练策略

# MLM 预训练任务

T5 模型的预训练任务采用 MLM（Masked Language Modeling），也称为 BERT-style 目标。该方法在输入文本中随机遮蔽 15% 的 token，然后训练模型预测这些被遮蔽的 token。

MLM任务的优势

MLM 任务的核心优势在于它是一个自监督学习任务，不需要人工标注的数据。通过遮蔽部分输入并预测这些遮蔽内容，模型能够学习到丰富的语言表示和上下文理解能力。这种预训练方式使得模型能够在大量未标注文本上进行训练。

# 文本到文本输入格式

预训练时，T5 将所有输入转换为 "文本到文本" 的统一格式：

  1. 对给定文本序列随机选择 token 进行遮蔽
  2. 用特殊占位符替换被遮蔽的 token
  3. 将被遮蔽的 token 序列作为模型的输出目标

这种统一的输入输出格式是 T5 的核心创新，它使得模型能够用相同的架构处理不同类型的 NLP 任务。

# C4 数据集

T5 使用自创建的大规模数据集 "Colossal Clean Crawled Corpus"（C4）进行预训练。

C4数据集特点

C4 数据集从 Common Crawl 中提取了大量干净的英语文本，经过严格的数据清洗过程：

  • 去除无意义的文本内容
  • 过滤重复文本
  • 移除不完整的句子
  • 确保文本质量和多样性
    这种高质量的预训练数据为 T5 的性能奠定了重要基础。

# 多任务学习与微调

# 多任务预训练

T5 还探索了将多个任务混合进行预训练的方法，而不仅仅局限于单独的 MLM 任务。这种多任务预训练策略有助于模型学习更通用的语言表示。

多任务预训练的益处

多任务预训练允许模型同时从不同类型的任务中学习，这种学习方式能够：

  • 提高模型的泛化能力
  • 减少任务间的负迁移
  • 促进不同任务间的知识共享
  • 提升在下游任务上的性能

# 预训练到微调的转换

预训练完成后，T5 模型在下游任务上进行微调：

  1. 在任务特定数据集上训练
  2. 根据具体任务调整解码策略
  3. 优化任务相关的损失函数

T5 的 "大一统思想" 将所有 NLP 任务统一为文本到文本的转换，这一理念在自然语言处理领域具有深远影响，为后续的大语言模型发展奠定了重要基础。
