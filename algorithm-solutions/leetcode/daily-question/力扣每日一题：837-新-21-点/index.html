# 📘 题目描述

爱丽丝参与一个大致基于纸牌游戏 “21 点” 规则的游戏，描述如下：

爱丽丝以 0 分开始，并在她的得分少于 k 分时抽取数字。 抽取时，她从 [1, maxPts] 的范围中随机获得一个整数作为分数进行累计，其中 maxPts 是一个整数。 每次抽取都是独立的，其结果具有相同的概率。

当爱丽丝获得 k 分 或更多分 时，她就停止抽取数字。

爱丽丝的分数不超过 n 的概率是多少？

与实际答案误差不超过 10−510^{-5}10−5 的答案将被视为正确答案。

  • 0 <= k <= n <= 10^4
  • 1 <= maxPts <= 10^4

# 🧠 解题思路

本题可以通过动态规划来解决。我们定义一个数组 dp ，其中 dp[i] 表示爱丽丝获得 i 分的概率。根据题意，我们可以得到以下状态转移方程：

  • 如果爱丽丝的分数小于 k ，则她可以继续抽取数字，状态转移为：

    dp[i]={1maxPts∑j=1idp[i−j]ifi≤maxPts1maxPts∑j=1maxPtsdp[i−j]ifi>maxPtsdp[i] = \begin{cases} \frac{1}{maxPts} \sum_{j=1}^{i} dp[i-j] & \text{if } i \leq maxPts \\ \frac{1}{maxPts} \sum_{j=1}^{maxPts} dp[i-j] & \text{if } i > maxPts \end{cases}dp[i]={maxPts1​∑j=1i​dp[i−j]maxPts1​∑j=1maxPts​dp[i−j]​if i≤maxPtsif i>maxPts​

  • 如果爱丽丝的分数大于等于 k ，则她停止抽取数字，状态转移为：

    dp[i]={0ifi−maxPts≥k1maxPts∑j=max⁡(1,i−k+1)maxPtsdp[i−j]ifi−maxPts<kdp[i] = \begin{cases} 0 & \text{if } i - maxPts \geq k \\ \frac{1}{maxPts} \sum_{j=\max(1, i-k+1)}^{maxPts} dp[i-j] & \text{if } i - maxPts < k \end{cases}dp[i]={0maxPts1​∑j=max(1,i−k+1)maxPts​dp[i−j]​if i−maxPts≥kif i−maxPts<k​

  • 特别的，爱丽丝获得零分的概率为 1。

最终，我们需要计算的结果为：

∑i=kndp[i]\sum_{i=k}^{n} dp[i]i=k∑n​dp[i]
