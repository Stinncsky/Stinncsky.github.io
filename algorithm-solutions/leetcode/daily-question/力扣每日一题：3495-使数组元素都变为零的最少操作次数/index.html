# 📘 题目描述

给你一个二维数组 queries ，其中 queries[i] 形式为 [l, r] 。每个 queries[i] 表示了一个元素范围从 l 到 r （包括 l 和 r ）的整数数组 nums 。

在一次操作中，你可以：

  • 选择一个查询数组中的两个整数 a 和 b 。
  • 将它们替换为 floor(a / 4) 和 floor(b / 4) 。

你的任务是确定对于每个查询，将数组中的所有元素都变为零的 最少 操作次数。返回所有查询结果的总和。

  • 1 <= queries.length <= 10^5
  • queries[i].length == 2
  • queries[i] == [l, r]
  • 1 <= l < r <= 10^9

# 🧠 解题思路

对于每一个数字 x ，它变为 0 需要的操作次数等于 floor(log4(x)) + 1 。是一个固定值，因此问题可以转化为计算每个查询区间 [l, r] 内所有整数转换为 0 所需操作次数这样一个数组，然后每次操作就是选择数组中的两个数各自减 1 ，直到所有数都变为 0 。
因此问题可以转化为计算每个查询区间 [l, r] 内所有整数转换为 0 所需操作次数之和，然后结果除以 2 向上取整即为答案。
因为操作次数连续，因此不用担心数组中某一个操作次数特别大，导致无法两两配对。只有奇数个操作次数时，才会多出 1 次操作。
然后可以选择批量计算每个 floor(log4(x)) 的贡献。假设 floor(log4(x)) = k ，那么 x 的范围是 [4^k, 4^(k+1) - 1] ，假设在范围内的数一共 b 个，每个数的操作次数为 k + 1 次，因此这个范围内的总操作次数为 b * (k + 1) 。。
