# 📘 题目描述

给你一个大小为 n x m 的二维整数矩阵 grid ，其中每个元素的值为 0、1 或 2。

V 形对角线段 定义如下：

  • 线段从 1 开始。
  • 后续元素按照以下无限序列的模式排列：2, 0, 2, 0, ...。
  • 该线段：
    • 起始于某个对角方向（左上到右下、右下到左上、右上到左下或左下到右上）。
    • 沿着相同的对角方向继续，保持 序列模式 。
    • 在保持 序列模式 的前提下，最多允许 一次顺时针 90 度转向 另一个对角方向。

返回最长的 V 形对角线段 的 长度 。如果不存在有效的线段，则返回 0。

  • n == grid.length
  • m == grid[i].length
  • 1 <= n, m <= 500
  • grid [i][j] 的值为 0、1 或 2。

# 🧠 解题思路

本题要求在一个二维矩阵中找到最长的 V 形对角线段。V 形对角线段的定义包括起始点为 1，后续元素按照 2, 0, 2, 0 的模式排列，并且允许最多一次顺时针转向。
可以使用深度优先搜索（DFS）来遍历每个可能的起始点，并尝试找到最长的 V 形对角线段。并进行状态记录以避免重复计算。
dp 数组用于记录每个点的状态，包括当前方向和是否已经转向。
只完成记忆化搜索会导致超时，因此需要进行剪枝。
最直接的剪枝方式是当当前找到的最长长度等于矩阵的最大边长时，直接返回结果。这样勉强可以过，耗时较长。
再进一步的剪枝方式是对于每一个开始递归的点，不同方向的最大长度是有限的，因此可以在递归前计算出该点在当前方向的最大可能长度，如果当前最长长度已经大于等于这个值，则不进行递归。
优化方法参考题解：记忆化搜索 + 最优性剪枝（Python/Java/C++/Go）

不过神奇的是，我优化之后的代码并不比简单优化的策略更快。通过时间都是 2700+ms。
