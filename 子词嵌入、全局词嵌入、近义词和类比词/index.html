# 跳字模型的数学表达与多重集概念

对于词 wiw_iwi​，它在数据集中可能多次出现。我们将每一次以它作为中心词的所有背景词全部汇总并保留重复元素，记作多重集（multiset）CiC_iCi​。

多重集与重数概念

多重集是允许元素重复出现的集合概念。一个元素在多重集中的个数称为该元素的重数（multiplicity）。这与普通集合不同，普通集合中每个元素只能出现一次。

举例来说，假设词 wiw_iwi​ 在数据集中出现 2 次：文本序列中以这 2 个 wiw_iwi​ 作为中心词的背景窗口分别包含背景词索引 2,1,5,22,1,5,22,1,5,2 和 2,3,2,12,3,2,12,3,2,1。那么多重集 Ci={1,1,2,2,2,2,3,5}C_i = \{1,1,2,2,2,2,3,5\}Ci​={1,1,2,2,2,2,3,5}，其中元素 1 的重数为 2，元素 2 的重数为 4，元素 3 和 5 的重数均为 1。

将多重集 CiC_iCi​ 中元素 jjj 的重数记作 xijx_{ij}xij​：它表示了整个数据集中所有以 wiw_iwi​ 为中心词的背景窗口中词 wjw_jwj​ 的个数。那么，跳字模型的损失函数还可以用另一种方式表达：

−∑i∈V∑j∈Vxijlog⁡qij-\sum_{i \in V} \sum_{j \in V} x_{ij} \log q_{ij}−i∈V∑​j∈V∑​xij​logqij​

我们将数据集中所有以词 wiw_iwi​ 为中心词的背景词的数量之和 ∣Ci∣|C_i|∣Ci​∣ 记为 xix_ixi​，并将以 wiw_iwi​ 为中心词生成背景词 wjw_jwj​ 的条件概率 xij/xix_{ij}/x_ixij​/xi​ 记作 pijp_{ij}pij​。我们可以进一步改写跳字模型的损失函数为：

−∑i∈Vxi∑j∈Vpijlog⁡qij-\sum_{i \in V} x_i \sum_{j \in V} p_{ij} \log q_{ij}−i∈V∑​xi​j∈V∑​pij​logqij​

上式中，−∑j∈Vpijlog⁡qij-\sum_{j \in V} p_{ij} \log q_{ij}−∑j∈V​pij​logqij​ 计算的是以 wiw_iwi​ 为中心词的背景词条件概率分布 pijp_{ij}pij​ 和模型预测的条件概率分布 qijq_{ij}qij​ 的交叉熵，且损失函数使用所有以词 wiw_iwi​ 为中心词的背景词的数量之和来加权。

最小化上式中的损失函数会令预测的条件概率分布尽可能接近真实的条件概率分布。

# GloVe 模型：全局向量表示

GloVe 模型采用了平方损失，并基于该损失对跳字模型做了 3 点关键改动：

# 核心改动

  1. 非概率变量使用：使用非概率分布的变量 pij′=xijp'_{ij} = x_{ij}pij′​=xij​ 和 qij′=exp⁡(ujTvi)q'_{ij} = \exp(\mathbf{u}_j^T \mathbf{v}_i)qij′​=exp(ujT​vi​)，并对它们取对数。因此，平方损失项是：

    (log⁡pij′−log⁡qij′)2=(ujTvi−log⁡xij)2(\log p'_{ij} - \log q'_{ij})^2 = (\mathbf{u}_j^T \mathbf{v}_i - \log x_{ij})^2(logpij′​−logqij′​)2=(ujT​vi​−logxij​)2

  2. 偏差项引入：为每个词 wiw_iwi​ 增加两个为标量的模型参数：中心词偏差项 bib_ibi​ 和背景词偏差项 cic_ici​。

  3. 权重函数：将每个损失项的权重替换成函数 h(xij)h(x_{ij})h(xij​)。权重函数 h(x)h(x)h(x) 是值域在 [0,1][0,1][0,1] 的单调递增函数。

权重函数的设计原理

权重函数的设计基于以下观察：在自然语言中，高频词对和低频词对的重要性不同。高频词对（如 "the" 和 "of"）虽然共现次数多，但语义信息有限；而中等频率的词对往往包含更丰富的语义信息。权重函数通过调节不同频率词对的贡献，平衡了模型的学习效果。

# GloVe 损失函数

GloVe 模型的目标是最小化损失函数：

∑i∈V∑j∈Vh(xij)(ujTvi+bi+cj−log⁡xij)2\sum_{i \in V} \sum_{j \in V} h(x_{ij})(\mathbf{u}_j^T \mathbf{v}_i + b_i + c_j - \log x_{ij})^2i∈V∑​j∈V∑​h(xij​)(ujT​vi​+bi​+cj​−logxij​)2

# 对称性特点

如果词 wiw_iwi​ 出现在词 wjw_jwj​ 的背景窗口里，那么词 wjw_jwj​ 也会出现在词 wiw_iwi​ 的背景窗口里。也就是说，xij=xjix_{ij} = x_{ji}xij​=xji​。

不同于 word2vec 中拟合的是非对称的条件概率 pijp_{ij}pij​，GloVe 模型拟合的是对称的 log⁡xij\log x_{ij}logxij​。因此，任意词的中心词向量和背景词向量在 GloVe 模型中是等价的。但由于初始化值的不同，同一个词最终学习到的两组词向量可能不同。

# 条件概率比值与向量设计

我们知道，任意一个这样的比值需要 3 个词 wiw_iwi​、wjw_jwj​ 和 wkw_kwk​。以 wiw_iwi​ 作为中心词的条件概率比值为 pij/pikp_{ij}/p_{ik}pij​/pik​。我们可以找一个函数，它使用词向量来拟合这个条件概率比值：

f(uj,uk,vi)≈pijpikf(\mathbf{u}_j, \mathbf{u}_k, \mathbf{v}_i) \approx \frac{p_{ij}}{p_{ik}}f(uj​,uk​,vi​)≈pik​pij​​

函数设计的数学推导

这里函数 fff 可能的设计并不唯一，我们需要考虑一种较为合理的可能性。注意到条件概率比值是一个标量，我们可以将 fff 限制为一个标量函数。同时考虑到向量运算的对称性和数学简洁性，我们选择特定的函数形式。

注意到条件概率比值是一个标量，我们可以将 fff 限制为一个标量函数：

f(uj,uk,vi)=f((uj−uk)Tvi)f(\mathbf{u}_j, \mathbf{u}_k, \mathbf{v}_i) = f((\mathbf{u}_j - \mathbf{u}_k)^T \mathbf{v}_i)f(uj​,uk​,vi​)=f((uj​−uk​)Tvi​)

交换索引 jjj 和 kkk 后可以看到函数 fff 应该满足 f(x)f(−x)=1f(x)f(-x) = 1f(x)f(−x)=1，因此一种可能是 f(x)=exp⁡(x)f(x) = \exp(x)f(x)=exp(x)，于是：

f(uj,uk,vi)=exp⁡(ujTvi)exp⁡(ukTvi)≈pijpikf(\mathbf{u}_j, \mathbf{u}_k, \mathbf{v}_i) = \frac{\exp(\mathbf{u}_j^T \mathbf{v}_i)}{\exp(\mathbf{u}_k^T \mathbf{v}_i)} \approx \frac{p_{ij}}{p_{ik}}f(uj​,uk​,vi​)=exp(ukT​vi​)exp(ujT​vi​)​≈pik​pij​​

满足最右边约等号的一种可能是 exp⁡(ujTvi)≈αpij\exp(\mathbf{u}_j^T \mathbf{v}_i) \approx \alpha p_{ij}exp(ujT​vi​)≈αpij​，这里 α\alphaα 是一个常数。考虑到 pij=xij/xip_{ij} = x_{ij}/x_ipij​=xij​/xi​，取对数后：

ujTvi≈log⁡α+log⁡xij−log⁡xi\mathbf{u}_j^T \mathbf{v}_i \approx \log \alpha + \log x_{ij} - \log x_iujT​vi​≈logα+logxij​−logxi​

我们使用额外的偏差项来拟合 −log⁡α+log⁡xi-\log \alpha + \log x_i−logα+logxi​，例如，中心词偏差项 bib_ibi​ 和背景词偏差项 cjc_jcj​：

ujTvi+bi+cj≈log⁡(xij)\mathbf{u}_j^T \mathbf{v}_i + b_i + c_j \approx \log(x_{ij})ujT​vi​+bi​+cj​≈log(xij​)

# 词向量的应用：近义词搜索

除了基本的词向量训练，我们还可以使用预训练词向量进行近义词搜索。基本思路是通过计算词向量间的余弦相似度来找到语义相近的词。

knn 函数通过计算查询词向量与词汇表中所有词向量的余弦相似度，返回最相似的 k 个词。余弦相似度的计算公式为：cos⁡(θ)=a⋅b∣a∣∣b∣\cos(\theta) = \frac{\mathbf{a} \cdot \mathbf{b}}{|\mathbf{a}||\mathbf{b}|}cos(θ)=∣a∣∣b∣a⋅b​

# 词向量的应用：类比词推理

除了求近义词以外，我们还可以使用预训练词向量求词与词之间的类比关系。例如，"man"（男人）: "woman"（女人）:: "son"（儿子） : "daughter"（女儿）是一个类比例子："man" 之于 "woman" 相当于 "son" 之于 "daughter"。

求类比词问题可以定义为：对于类比关系中的 4 个词 a:b::c:da:b::c:da:b::c:d，给定前 3 个词 aaa、bbb 和 ccc，求 ddd。设词 www 的词向量为 vec(w)\text{vec}(w)vec(w)。

类比词的数学原理

类比词推理的核心思想是词向量空间中的线性关系能够反映语义关系。如果两对词之间存在相同的语义关系，那么它们在向量空间中的差向量应该相似。例如，vec(woman)−vec(man)\text{vec}(\text{woman}) - \text{vec}(\text{man})vec(woman)−vec(man) 应该近似等于 vec(daughter)−vec(son)\text{vec}(\text{daughter}) - \text{vec}(\text{son})vec(daughter)−vec(son)，因为它们都表示 "性别转换" 这一语义关系。

求类比词的思路是，搜索与 vec(c)+vec(b)−vec(a)\text{vec}(c) + \text{vec}(b) - \text{vec}(a)vec(c)+vec(b)−vec(a) 的结果向量最相似的词向量。

这个函数实现了类比推理：给定三个词 aaa、bbb、ccc，计算 vec(b)−vec(a)+vec(c)\text{vec}(b) - \text{vec}(a) + \text{vec}(c)vec(b)−vec(a)+vec(c)，然后在词汇表中找到与这个向量最相似的词作为答案 ddd。
