# BERT 模型架构与核心组件

BERT 模型采用 Encoder-only 架构，整体由三个核心组件构成：Embedding 层、Encoder 层和 prediction_heads。

BERT 模型 = Embedding 层 + Encoder 层 + prediction_heads

# 数据流转与处理流程

输入文本的处理流程如下：

  1. Tokenization: 输入文本通过 tokenizer 转化为 input_ids
  2. Embedding: input_ids 经过 Embedding 层转化为特定维度的 hidden_states
  3. Encoding: hidden_states 通过多层 Encoder 进行编码
  4. Prediction: 最顶层 hidden_states 经过 prediction_heads 得到类别概率
  5. Output: 通过 Softmax 计算得到最终预测类别
Tokenizer 机制详解

Tokenizer 是将原始文本转换为模型可处理的数字序列的关键组件。它负责将连续的文本切分为离散的 token，并为每个 token 分配唯一的数字标识符（token ID）。这个过程包括文本预处理、词汇切分、特殊符号添加等步骤，是连接人类语言和机器理解的重要桥梁。

# WordPiece 分词算法

BERT 采用 WordPiece 作为核心分词方法。WordPiece 是一种基于统计的子词切分算法，通过将单词拆解为子词来处理词汇表外（OOV）问题。

WordPiece 算法原理

WordPiece 算法的核心思想是将罕见词汇分解为更常见的子词单元。例如，"playing" 会被切分为 ["play", "##ing"]，其中 "##" 表示该子词是前一个词的延续。算法的合并操作基于最大化语言模型似然度的原则，优先保留那些能够提升模型整体性能的子词组合。对于中文等非空格分隔语言，通常将单个汉字作为原子分词单位处理。

算法特点：

  • 有效处理词汇表外问题
  • 平衡词汇表大小与表示能力
  • 基于统计学习最优切分策略

# Encoder Layer 的内部结构

每个 Encoder Layer 采用与 Transformer 相似的架构，但在实现细节上有所优化。

# 注意力机制与位置编码

BERT 的注意力机制与 Transformer Encoder 的自注意力机制基本一致，但将相对位置编码融合到注意力计算中。

关键差异：

  • 在注意力分数计算后，通过 Position Embedding 层融入相对位置信息
  • Position Embedding 层实际上是一个线性变换矩阵
  • 相对位置编码作为可训练参数参与模型优化

# Intermediate 层设计

Intermediate 层是 BERT 对前馈网络的特殊命名，本质上是线性层加激活函数的组合。

Intermediate 层 = 线性变换 + GELU 激活函数

BPE 算法背景

BPE（Byte Pair Encoding）是另一种流行的子词分割算法，最初用于数据压缩。在 NLP 中，BPE 通过迭代合并最频繁出现的字符对来构建词汇表。与 WordPiece 相比，BPE 更侧重于字符级别的统计频率，而 WordPiece 更注重语言模型的似然度优化。

# GELU 激活函数

BERT 使用 GELU（Gaussian Error Linear Unit）作为激活函数，其数学表达式为：

GELU(x)=0.5x(1+tanh⁡(2π(x+0.044715x3)))\text{GELU}(x) = 0.5x\left(1 + \tanh\left(\sqrt{\frac{2}{\pi}}\left(x + 0.044715x^3\right)\right)\right)GELU(x)=0.5x(1+tanh(π2​​(x+0.044715x3)))

GELU 函数设计思想

GELU 将随机正则化思想引入激活函数设计。它根据输入值的概率分布来决定是否保留对应的神经元激活。具体而言，GELU 可以看作是 ReLU 和 Dropout 的结合体，在提供非线性变换的同时引入了随机性，有助于模型的泛化能力。与传统的 ReLU 相比，GELU 提供了更平滑的激活曲线。

GELU 优势：

  • 平滑的激活曲线，避免硬截断
  • 引入随机正则化效应
  • 更好的梯度流动特性

# 预训练任务与策略

# MLM（Masked Language Modeling）训练策略

MLM 是 BERT 的核心预训练任务，采用精心设计的 token 遮蔽策略。

15% Token 遮蔽分配：

  • 80% 被替换为 <MASK> 标记
  • 10% 被替换为随机 token
  • 10% 保持原始状态不变

10% 保持不变策略消除了预训练与微调阶段的输入分布差异

10% 随机替换的作用：

  • 迫使模型依赖上下文信息进行预测
  • 提高模型对输入扰动的鲁棒性
  • 避免模型过度依赖 <MASK> 标记

10% 保持不变的意义：

  • 在没有 <MASK> 标记时也要求模型预测
  • 通过上下文学习进行 token 预测
  • 减少预训练和微调阶段的分布偏移

# NSP（Next Sentence Prediction）任务

NSP 任务要求模型判断句对中两个句子是否为连续的上下文关系。

# BERT 模型优化与变体

# RoBERTa 的关键改进

RoBERTa 针对 BERT 的训练策略进行了三项重要优化：

优化一：移除 NSP 任务

  • 实验表明 NSP 任务对模型性能提升有限
  • 简化预训练目标，专注于 MLM 任务

优化二：动态遮蔽策略

  • Mask 操作在训练阶段动态执行
  • 每个 Epoch 的遮蔽位置都不相同
  • 增加训练数据的多样性

优化三：扩大训练规模

  • 使用更大规模的预训练数据集
  • 增加预训练步数
  • 扩大 BPE 词汇表规模

# ALBERT 的参数优化策略

ALBERT 通过三种创新技术显著减少了模型参数：

# 优化一：Embedding 参数分解

ALBERT 将 Embedding 层参数矩阵进行分解，解耦 Embedding 维度与隐藏层维度。

参数量变化：

  • 原始参数量：V×HV \times HV×H
  • 优化后参数量：V×E+E×HV \times E + E \times HV×E+E×H

其中 VVV 为词汇表大小，HHH 为隐藏层维度，EEE 为 Embedding 维度（设为 128）。

实现方式：

  • Embedding 层输出维度设为 128
  • 添加 128×1024128 \times 1024128×1024 的线性矩阵进行维度变换

# 优化二：跨层参数共享

ALBERT 在所有 Encoder 层之间共享参数，虽然计算次数不变，但参数量大幅减少。

参数共享导致训练和推理速度比 BERT 更慢，这是 ALBERT 未能完全取代 BERT 的重要原因

实现细节：

  • 仅初始化一个 Encoder 层
  • 24 次计算均通过同一个 Encoder 层
  • 参数量减少但计算复杂度不变

# 优化三：SOP 预训练任务

ALBERT 提出 SOP（Sentence Order Prediction）任务替代 NSP，要求模型预测句子顺序而非连续性。

# prediction_heads 设计

prediction_heads 是 BERT 面向下游任务的输出层，由线性层和激活函数组成。

核心特点：

  • 最后一个线性层输出维度等于任务类别数
  • 通过 Softmax 函数输出类别概率分布
  • 可根据具体任务灵活调整网络结构
