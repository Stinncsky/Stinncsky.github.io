# 概念基础：词嵌入与 word2vec

词嵌入（Word Embedding）是将词语转换为数值向量的技术，使计算机能够理解词语间的语义关系。Word2vec 是最经典的词嵌入方法之一，主要包含两种模型：跳字模型（Skip-gram）和连续词袋模型（CBOW）。

什么是词嵌入

词嵌入将每个词映射到一个固定维度的实数向量空间中，相似语义的词在向量空间中距离较近。与传统的独热编码不同，词嵌入可以捕获词语间的语义关系，如 "国王" 与 "王后"、"男人" 与 "女人" 之间的关系可以通过向量运算体现。

# 跳字模型（Skip-gram）原理

跳字模型的核心思想是基于某个词来生成它在文本序列周围的词。在跳字模型中，每个词被表示成两个ddd 维向量，用来计算条件概率。

# 连续词袋模型（CBOW）原理

连续词袋模型与跳字模型的主要区别在于，CBOW 假设基于某中心词在文本序列前后的背景词来生成该中心词。

设vi∈Rd\mathbf{v}_i \in \mathbb{R}^dvi​∈Rd 和ui∈Rd\mathbf{u}_i \in \mathbb{R}^dui​∈Rd 分别表示词典中索引为iii 的词作为背景词和中心词的向量。设中心词wcw_cwc​ 在词典中索引为ccc，背景词wo1,…,wo2mw_{o_1}, \ldots, w_{o_{2m}}wo1​​,…,wo2m​​ 在词典中索引为o1,…,o2mo_1, \ldots, o_{2m}o1​,…,o2m​。

# softmax 优化：负采样方法

由于 softmax 计算需要遍历整个词典，计算开销巨大。负采样通过将多分类问题转化为二分类问题来优化计算。

# 基本原理

负采样将给定中心词wcw_cwc​ 的一个背景窗口中，背景词wow_owo​ 出现看作一个事件，概率计算为：

在 word2vec 的负采样训练中，D=1D=1D=1 表示 "这是一个真实的（正样本）词对"，D=0D=0D=0 表示 "这是一个假的（负样本）词对"。例如，句子中出现 "I like apple" 时，中心词 "like" 和背景词 "apple" 构成真实共现，对应D=1D=1D=1；而随机采样的无关词对如 "like" 和 "table" 对应D=0D=0D=0。
