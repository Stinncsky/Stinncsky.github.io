# 效率优化的动机与背景

标准自注意力机制的计算复杂度为 O(n2)O(n^2)O(n2)，其中 nnn 为序列长度。当输入序列很长时，attention 的运算占比显著增加，因此各种加速优化方法才会产生实际效果。

只有在处理长序列任务时，attention 优化才能带来明显的性能提升

# 稀疏化方法：减少计算范围

# Local Attention 与 Truncated Attention

Local attention 通过限制每个位置只关注其邻近位置来降低计算复杂度。具体实现是将 attention 矩阵中距离超过窗口大小的部分直接设置为 0。

Local Attention 原理详解

Local attention 基于一个重要假设：对于大多数序列建模任务，远距离的依赖关系相对较弱，局部依赖关系更为重要。通过引入窗口机制，每个 token 只需要计算与其周围固定窗口内 token 的 attention 权重，从而将复杂度从 O(n2)O(n^2)O(n2) 降低到 O(n⋅w)O(n \cdot w)O(n⋅w)，其中 www 是窗口大小。

# Strided Attention

Strided attention 采用 "跳跃式" 计算策略，不是连续地计算所有位置的 attention，而是按照固定步长进行采样计算。

Strided Attention 实现细节

该方法将序列按照固定步长 sss 进行分组，每个 token 只与其所在组内以及相邻几个组内的 token 计算 attention。这种方法在保持一定长距离依赖能力的同时，显著降低了计算量。常见的实现是将 attention 计算分为两个阶段：局部 attention 和步长 attention。

# 全局信息整合：Global Attention 机制

Global attention 通过引入特殊 token 来平衡效率和性能。这些特殊 token 负责收集和分发全局信息。

实现方式分为两种：

  • 添加特殊 token：在序列中插入专门的全局 token
  • 标记现有 token：将部分重要 token 标记为具有全局 attention 能力
Global Token 的工作机制

全局 token 具有双向的特殊地位：它们会关注序列中的所有 token（收集全局信息），同时也会被所有 token 关注（分发全局信息）。这种设计使得模型能够在局部 attention 的基础上，通过少量全局 token 来维持长距离依赖关系的建模能力。

# 代表性模型：Longformer 与 Big Bird

这两个模型都采用了混合 attention 模式，结合了局部、全局和随机 attention 模式。

Longformer 与 Big Bird 对比

Longformer 使用滑动窗口局部 attention，并为特定位置设置全局 attention。Big Bird 则采用了更复杂的稀疏模式，包括随机 attention、窗口 attention 和全局 attention 的组合。Big Bird 在理论上证明了其稀疏 attention 模式能够逼近全 attention 的表达能力。

# 聚类与选择方法：智能化计算

# Clustering Attention

通过将查询向量 qqq 和键向量 kkk 进行聚类，只在同一类别内计算 attention，从而减少不必要的计算。

聚类方法的数学表述：

Attention(Q,K,V)=∑cAttention(Qc,Kc,Vc)\text{Attention}(Q, K, V) = \sum_{c} \text{Attention}(Q_c, K_c, V_c)Attention(Q,K,V)=c∑​Attention(Qc​,Kc​,Vc​)

其中 Qc,Kc,VcQ_c, K_c, V_cQc​,Kc​,Vc​ 分别表示聚类 ccc 中的查询、键、值向量。

聚类方法的实现挑战

聚类 attention 的主要挑战在于如何高效地进行聚类以及如何确保聚类结果的质量。常用的方法包括 K-means 聚类、locality-sensitive hashing (LSH) 等。聚类的准确性直接影响模型的性能，因此需要在计算效率和聚类质量之间找到平衡。

# 选择性计算策略

另一种方法是从 NNN 个键向量中选出一部分进行计算，同时对查询向量也进行相应的选择，保持计算的对称性。

Sinkhorn Sorting Network

Sinkhorn Sorting Network 是一种可微分的排序网络，能够学习如何选择最重要的键值对进行 attention 计算。它使用 Sinkhorn 算法来近似排列矩阵，从而实现端到端的可训练选择机制。这种方法的优势在于能够自适应地学习哪些位置对当前查询最重要。

# 压缩与降维技术

# Compressed Attention

使用卷积操作对键值矩阵进行压缩，减少 attention 计算的维度。

压缩后的 attention 计算：

Attention(Q,Kcompressed,Vcompressed)\text{Attention}(Q, K_{compressed}, V_{compressed})Attention(Q,Kcompressed​,Vcompressed​)

其中 KcompressedK_{compressed}Kcompressed​ 和 VcompressedV_{compressed}Vcompressed​ 通过卷积操作获得。

# Linformer：线性变换优化

Linformer 通过线性投影将键值矩阵的序列长度维度从 nnn 降低到固定的 kkk，从而实现线性复杂度。

数学表述：

K′=KEK,V′=VEVK' = KE_K, \quad V' = VE_VK′=KEK​,V′=VEV​

其中 EK,EV∈Rn×kE_K, E_V \in \mathbb{R}^{n \times k}EK​,EV​∈Rn×k 是可学习的投影矩阵。

Linformer 的理论基础

Linformer 基于一个重要观察：在实际的 attention 矩阵中，大部分信息集中在低秩子空间中。通过线性投影，可以在保持主要信息的同时显著降低计算复杂度。实验表明，即使 kkk 远小于 nnn，模型性能也能得到很好的保持。

# 函数近似方法：Linear Attention

通过函数变换将 attention 计算重新组织，实现线性复杂度。

核心思想是利用以下等式：

exp⁡(q⋅k)=ϕ(q)⋅ϕ(k)\exp(q \cdot k) = \phi(q) \cdot \phi(k)exp(q⋅k)=ϕ(q)⋅ϕ(k)

其中 ϕ\phiϕ 是某种特征映射函数。

重新组织 attention 计算：

Attention(Q,K,V)=ϕ(Q)(ϕ(K)TV)ϕ(Q)(ϕ(K)T1)\text{Attention}(Q, K, V) = \frac{\phi(Q)(\phi(K)^TV)}{\phi(Q)(\phi(K)^T\mathbf{1})}Attention(Q,K,V)=ϕ(Q)(ϕ(K)T1)ϕ(Q)(ϕ(K)TV)​

通过这种变换，ϕ(K)TV\phi(K)^TVϕ(K)TV 和 ϕ(K)T1\phi(K)^T\mathbf{1}ϕ(K)T1 可以预先计算，避免了 O(n2)O(n^2)O(n2) 的复杂度。

特征映射函数的选择

常用的特征映射函数包括随机特征映射、正交随机特征、以及基于核方法的映射。不同的映射函数会影响近似的质量和计算效率。例如，使用随机 Fourier 特征可以近似 RBF 核，而正交随机特征则能提供更稳定的近似效果。

# 学习式方法：Synthesizer

Synthesizer 完全摒弃了基于内容的 attention 计算，转而使用可学习的参数来生成 attention 权重。

Synthesizer 的设计理念

Synthesizer 提出了一个激进的观点：attention 权重不一定需要通过查询和键的交互来计算，而可以直接学习。它包含两种变体：Dense Synthesizer（使用全连接层生成权重）和 Random Synthesizer（使用固定的随机权重）。实验表明，在某些任务上，学习到的固定模式甚至能够超越动态计算的 attention。

Random Attention 补充说明

Random attention 是一种极简的稀疏化方法，随机选择一部分位置对进行 attention 计算。虽然看似简单，但在某些长序列任务中表现出了意外的有效性，这表明并非所有的 attention 连接都是必要的，为后续的稀疏化研究提供了重要启发。
