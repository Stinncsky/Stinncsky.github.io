# 基于偏置调节的微调方法

# BitFit：极简参数微调策略

BitFit 是一种稀疏的微调方法，训练时只更新偏置参数（bias）或部分偏置参数。该方法在多个数据集上都达到了不错的效果，虽不及全量参数微调，但远超固定全部模型参数的 Frozen 方式。

偏置参数的作用机制

偏置参数（bias）是神经网络中的重要组成部分，为每个神经元提供一个常数偏移量。在 Transformer 架构中，偏置参数主要存在于注意力机制的线性变换层和前馈神经网络层中。这些参数虽然数量相对较少，但对模型的表达能力有着重要影响。

通过对比 BitFit 训练前后的参数变化，研究发现：

  • 许多偏置参数变化不大（如计算 key 相关的偏置参数）
  • 计算 query 的偏置参数和 FFN 中间层（intermediate）的偏置参数变化最为明显
  • 仅更新这两类偏置参数也能达到不错效果
  • 固定其中任一类别，模型效果都有较大损失

BitFit 的核心洞察：模型微调过程中，关键的适应性调整主要发生在查询计算和特征维度扩展环节的偏置参数上。

# 基于提示学习的微调方法

# Prefix Tuning：可学习的任务前缀

Prefix Tuning 固定预训练模型参数，为模型添加可训练的任务特定前缀。该方法实际使用连续可微的虚拟标记（Soft Prompt/Continuous Prompt），相比离散标记更易优化。

软提示vs硬提示

传统的提示（Hard Prompt）是人工设计的离散文本，如 "翻译以下句子："。而软提示（Soft Prompt）是可学习的连续向量表示，不对应具体的词汇，但能够引导模型产生期望的行为。软提示通过梯度下降直接优化，具有更强的表达能力。

该方法的关键设计包括：

  • MLP 缓冲结构：为防止直接更新前缀参数导致训练不稳定，在前缀层前增加 MLP 结构，训练完成后只保留前缀参数
  • 多层插入：在 Transformer 的每一层都加入提示参数，避免仅调整嵌入层表现力不足的问题
  • 位置优势：实验证实 Prefix-tuning（ [PREFIX; x; y] ）略优于 Infix-tuning（ [x; INFIX; y] ）

# Prompt Tuning：简化版前缀调优

Prompt Tuning 可视为 Prefix Tuning 的简化版本，为每个任务定义专用的提示，然后拼接到输入数据上。

关键特点：

  • 仅在输入层加入提示标记
  • 无需 MLP 调整来解决训练困难问题
  • 规模效应：随着预训练模型参数量增加，方法效果逼近全参数微调

Prompt Tuning 提出了提示集成（Prompt Ensembling）技术：在同一批次中训练同一任务的不同提示表达方式，相当于低成本的模型集成。

# P-Tuning 系列方法

# P-Tuning v1：增强提示表示

P-Tuning 设计连续可微的虚拟标记，将提示转换为可学习的嵌入层。

技术特色：

  • 使用 MLP+LSTM 对提示嵌入进行编码处理
  • 虚拟标记位置可选择，不限于前缀位置
  • 提示编码器使模型收敛更快，效果更佳
LSTM在提示编码中的作用

LSTM（长短期记忆网络）能够捕捉序列中的长期依赖关系。在 P-Tuning 中，LSTM 编码器帮助学习提示标记之间的相互依赖关系，使得生成的软提示能够更好地表达任务需求，提升模型在小规模数据上的表现。

# P-Tuning v2：深度提示优化

针对前期方法的两个主要问题：

  1. 缺乏规模和任务通用性
  2. 缺少深度提示优化

P-Tuning v2 在每一层都加入提示标记，带来双重优势：

  • 参数规模适中：从 0.01% 增加到 0.1%-3%，保持参数高效性
  • 直接深层影响：深层结构中的提示对模型预测产生更直接影响

# 提示方法对比分析

方法插入位置深层影响参数规模适用模型核心贡献
Prompt Tuning输入层嵌入❌最小大模型效果佳软提示嵌入

# 基于适配器的微调方法

# Adapter Tuning：模块化微调架构

Adapter Tuning 在 Transformer 结构中嵌入轻量化的适配器模块。针对每个 Transformer 层，在两个位置增加适配器：

  1. 多头注意力的投影之后
  2. 前馈神经网络层之后

训练时固定预训练模型参数，只微调新增的 Adapter 结构和 Layer Norm 层。

Adapter的设计原理

Adapter 通常采用瓶颈结构（bottleneck architecture），包含降维 - 升维两个线性变换，中间通过较小的隐藏维度。这种设计既保证了参数效率，又提供了足够的表达能力来学习任务特定的表示变换。

# AdapterFusion：多任务知识融合

AdapterFusion 通过两阶段训练来融合多任务信息：

# 知识提取阶段

采用两种训练策略：

Single-Task Adapters (ST-A)
对 N 个任务分别独立优化，各任务互不干扰

Multi-Task Adapters (MT-A)
N 个任务通过多任务学习联合优化

# 知识组合阶段

固定预训练模型和任务特定适配器参数，引入 AdapterFusion 模块学习组合多个适配器的知识。

AdapterFusion 结构采用注意力机制：

  • Query：Transformer 各子模块的输出
  • Key/Value：N 个任务适配器的输出
  • 通过注意力权重聚合不同任务信息

AdapterFusion 通过固定已学习参数的方式有效避免了灾难性遗忘问题，同时实现了多任务知识的有效整合。

# AdapterDrop：动态适配器剪枝

AdapterDrop 在不影响任务性能的前提下，动态移除适配器模块，减少参数量并提高计算效率。

实验结果显示：

  • 可移除 AdapterFusion 中的大多数适配器而不影响性能
  • 使用两个适配器即可达到八个适配器的完整模型效果
  • 推理速度提升 68%

# 基于低秩分解的微调方法

# LoRA：低秩适应性微调

LoRA（Low-Rank Adaptation）通过低秩分解模拟参数变化，以极小参数量实现大模型间接训练。

# 核心机制

在原始预训练模型旁增加新的通路，通过两个矩阵相乘实现参数更新：

W+ΔW=W+BA\mathbf{W} + \Delta\mathbf{W} = \mathbf{W} + \mathbf{B}\mathbf{A}W+ΔW=W+BA

其中：

  • A∈Rr×d\mathbf{A} \in \mathbb{R}^{r \times d}A∈Rr×d：降维矩阵
  • B∈Rd×r\mathbf{B} \in \mathbb{R}^{d \times r}B∈Rd×r：升维矩阵
  • r≪dr \ll dr≪d：低秩瓶颈维度
低秩分解的数学基础

低秩分解基于这样的假设：微调过程中权重矩阵的变化具有较低的内在维度（intrinsic dimensionality）。通过将大矩阵分解为两个小矩阵的乘积，可以用更少的参数近似表示原始的权重更新，这在保持表达能力的同时大幅减少了可训练参数数量。

# 关键发现

实验表明：

  • 权重矩阵种类数量比增加隐藏维度 r 更重要
  • 增加 r 不一定覆盖更有意义的子空间

# AdaLoRA：自适应低秩分配

AdaLoRA 根据重要性评分动态分配参数预算，是对 LoRA 的改进。

# 核心策略

  1. 调整增量矩阵分配：关键矩阵分配高秩捕捉精细信息，次要矩阵降低秩防止过拟合
  2. 奇异值分解参数化：以 SVD 形式参数化增量更新，根据重要性指标裁剪不重要的奇异值
  3. 正交性约束：在训练损失中添加惩罚项规范奇异矩阵的正交性

数学表示：

ΔW=PΛQT\Delta\mathbf{W} = \mathbf{P}\boldsymbol{\Lambda}\mathbf{Q}^TΔW=PΛQT

其中P\mathbf{P}P、Q\mathbf{Q}Q 为正交矩阵，Λ\boldsymbol{\Lambda}Λ 为对角奇异值矩阵。

# QLoRA：量化低秩适配

QLoRA 将量化技术与 LoRA 结合，使用 4-bit 量化存储预训练模型，同时保持 16-bit 计算精度。

# 核心技术

  1. 4-bit NormalFloat (NF4)：针对正态分布权重的信息理论最优量化数据类型
  2. 双量化：对第一次量化的常量再次量化，进一步减少存储空间
  3. 分页优化器：利用 NVIDIA 统一内存特性，在 GPU 内存不足时自动进行 CPU-GPU 间的数据传输

实验证明：无论使用 16-bit、8-bit 还是 4-bit 适配器，都能复制 16-bit 全参数微调的基准性能，完全恢复量化过程中的性能损失。

# 混合与统一方法

# MAM Adapter：统一适配框架

MAM Adapter 在 Adapter、Prefix Tuning 和 LoRA 之间建立统一联系。

# 核心发现

通过详细调研得出：

  • 并行放置的适配器优于顺序放置
  • 与 FFN 并行的适配器优于与多头注意力并行的适配器
  • 软提示可通过仅更改 0.1% 参数有效修改注意力机制

最终模型采用 FFN 层并行适配器与软提示的组合。

# UniPELT：门控组合方法

UniPELT 是 LoRA、Prefix Tuning 和 Adapter 的门控组合系统。

# 架构设计

  • LoRA 重参数化：应用于WQ\mathbf{W}_QWQ​ 和WV\mathbf{W}_VWV​ 注意力矩阵
  • Prefix Tuning：应用于每层的 key 和 value
  • Adapter：添加在前馈子层之后

# 门控机制

通过线性层实现的门控函数：

  • GPG_PGP​：控制 Prefix Tuning 开关
  • GLG_LGL​：控制 LoRA 开关
  • GAG_AGA​：控制 Adapter 开关
门控机制的优势

门控机制允许模型自动学习在不同情况下激活哪种 PEFT 方法，实现了方法间的动态平衡。这种设计不仅提升了单一方法的上限，还增强了模型的鲁棒性，使其能够适应更广泛的任务场景。

UniPELT 始终优于传统全量微调及其包含的各个子模块，证明了多种 PEFT 方法的混合对模型有效性和鲁棒性都有显著益处。

# 总体技术发展趋势

参数高效微调技术的发展体现了从单一策略到混合方法，从粗粒度调整到精细化控制的演进趋势。这些方法在保持模型性能的同时，显著降低了计算成本和存储需求，为大模型的实际应用提供了重要支撑。
