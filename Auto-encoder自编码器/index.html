# 基本原理与架构

自编码器（Auto-encoder）是一种无监督学习的神经网络架构，其核心思想是通过编码器将输入数据压缩为低维表示，再通过解码器重构原始输入。

自编码器的目标是使输出尽可能接近输入，即最小化重构误差：L=∣∣x−x^∣∣2\mathcal{L} = ||x - \hat{x}||^2L=∣∣x−x^∣∣2

类似于 CycleGAN 的循环一致性思想，自编码器通过 encoder 将输入xxx 映射到隐藏表示zzz，再通过 decoder 将zzz 重构为输出x^\hat{x}x^，要求x^\hat{x}x^ 与原始输入xxx 尽可能接近。

整个过程可以表示为：

x→encoderz→decoderx^x \xrightarrow{\text{encoder}} z \xrightarrow{\text{decoder}} \hat{x}xencoder​zdecoder​x^

其中：

  • 编码器（Encoder）：z=fϕ(x)z = f_{\phi}(x)z=fϕ​(x)，将高维输入映射到低维隐空间
  • 解码器（Decoder）：x^=gθ(z)\hat{x} = g_{\theta}(z)x^=gθ​(z)，从隐表示重构原始数据
VAE详解

变分自编码器（Variational Auto-Encoder, VAE）是自编码器的概率化扩展。与传统自编码器不同，VAE 在编码过程中不是直接输出确定的隐向量，而是输出隐变量的概率分布参数（均值μ\muμ 和方差σ2\sigma^2σ2）。

VAE 的核心创新在于：

  1. 概率编码：编码器输出μ(x)\mu(x)μ(x) 和σ(x)\sigma(x)σ(x)，隐变量z∼N(μ(x),σ(x))z \sim \mathcal{N}(\mu(x), \sigma(x))z∼N(μ(x),σ(x))
  2. KL 散度正则化：损失函数包含重构误差和 KL 散度项
  3. 可控生成：通过在隐空间采样可以生成新的数据样本

VAE 的损失函数为：

L=Eq(z∣x)[log⁡p(x∣z)]−DKL(q(z∣x)∣∣p(z))\mathcal{L} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{KL}(q(z|x)||p(z))L=Eq(z∣x)​[logp(x∣z)]−DKL​(q(z∣x)∣∣p(z))

这种设计使得 VAE 既能进行数据重构，又能进行数据生成。

# 降维与特征提取

通过编码器得到的隐表示通常是压缩后的低维向量，这种压缩表示可以用于其他任务的降维（dimension reduction）。

高维数据的有效性往往有限，真实的数据分布通常位于高维空间中的低维流形上。自编码器能够学习到这种内在的低维结构，因为：

  1. 数据冗余性：高维数据中存在大量冗余信息
  2. 内在规律：数据往往遵循某些潜在的规律和模式
  3. 流形假设：真实数据分布在高维空间的低维流形上

有效的降维要求隐向量维度远小于输入维度，否则模型可能学到恒等映射

自编码器学习到的低维表示具有以下优势：

  • 压缩效率：去除冗余信息，保留关键特征
  • 语义意义：隐向量的每个维度可能对应特定的语义属性
  • 迁移能力：学到的表示可用于下游任务

# 去噪自编码器

去噪自编码器（Denoising Auto-encoder）是自编码器的重要变种，通过在训练时向原始输入添加噪音，要求模型输出尽量接近无噪音的原始输入。

训练过程为：

x~=x+ϵ,ϵ∼N(0,σ2)\tilde{x} = x + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)x~=x+ϵ,ϵ∼N(0,σ2)

L=∣∣x−f(g(x~))∣∣2\mathcal{L} = ||x - f(g(\tilde{x}))||^2L=∣∣x−f(g(x~))∣∣2

其中x~\tilde{x}x~ 是加噪后的输入，fff 和ggg 分别是解码器和编码器。

去噪训练强制模型学习数据的本质特征，而非记忆输入细节，提高了模型的泛化能力

去噪自编码器的优势：

  • 鲁棒性增强：对输入扰动具有更强的抗性
  • 特征提取：学到更加本质的数据表示
  • 正则化效果：防止模型过拟合

# 特征解耦

特征解耦（Feature Disentanglement）是指将复杂的数据表示分解为多个相互独立的语义因子，每个因子控制数据的一个特定属性。

特征解耦的挑战

特征解耦是无监督学习中的一个重要但困难的问题：

  1. 识别性问题：在无额外约束下，解耦的表示不是唯一的
  2. 评估困难：缺乏标准的定量评估指标
  3. 语义对齐：学到的因子可能与人类理解的语义不对齐

常用的解耦方法包括：

  • β-VAE：增大 KL 散度权重，鼓励隐变量独立
  • Factor-VAE：直接优化因子间的独立性
  • β-TCVAE：分解 KL 散度为不同的信息论项

在自编码器框架下，特征解耦通过以下方式实现：

  • 独立性约束：鼓励隐向量的不同维度相互独立
  • 语义一致性：确保特定维度始终控制相同的语义属性
  • 可控性：通过调整特定维度实现对生成结果的控制

# 离散表示

离散表示（Discrete Representation）是指使用离散的符号或类别来编码数据，而非连续的实数向量。

离散表示的实现方法

常见的离散表示学习方法包括：

  1. VQ-VAE（Vector Quantized VAE）：

    • 维护一个可学习的离散码本（codebook）
    • 编码器输出与码本中最近的向量匹配
    • 通过 straight-through estimator 进行梯度传播

  2. Gumbel-Softmax：

    • 使用连续松弛的方法近似离散采样
    • 通过温度参数控制离散程度
    • 允许端到端的梯度优化

  3. 向量量化：

    zq=arg⁡min⁡ei∈E∣∣ze−ei∣∣2z_q = \arg\min_{e_i \in \mathcal{E}} ||z_e - e_i||_2zq​=argei​∈Emin​∣∣ze​−ei​∣∣2​

    其中zez_eze​ 是编码器输出，E\mathcal{E}E 是码本。

离散表示的优势包括：

  • 解释性：离散符号更容易理解和分析
  • 压缩效率：大幅减少存储空间需求
  • 组合性：支持符号间的组合和推理
  • 稳定性：避免连续空间中的数值不稳定问题

离散表示在语言模型、图像生成和强化学习等领域都有重要应用
