# 强化学习基础

强化学习 (Reinforcement Learning, RL) 是机器学习的一个重要分支，特别适用于任务困难且无法获得正确答案，但能够判断行为好坏的场景。与监督学习不同，强化学习通过与环境交互来学习最优策略。

# 核心架构

强化学习的基本架构包含两个核心组件：智能体 (Actor) 和 环境 (Environment)。

  • 环境向智能体提供 ** 观察 (Observation)** 作为输入
  • 智能体根据观察产生 ** 动作 (Action)** 作为输出
  • 环境持续向智能体提供 ** 奖励 (Reward)** 反馈
  • 智能体的目标是最大化累积奖励

强化学习的架构与传统机器学习相似，但损失函数为负的总奖励 (Return)

环境与奖励的特性

在强化学习中，环境 (Environment) 和奖励函数 (Reward Function) 通常被视为黑盒系统。这意味着我们无法直接了解环境的内部机制，只能通过与环境交互来获得反馈信息。这种设计反映了现实世界中许多决策问题的本质特征。

# 训练过程与随机性

一个完整的训练序列称为回合 (Episode)。强化学习的一个重要特征是输出需要采样，因此相同状态可能产生不同的动作，这种随机性是探索未知环境的关键机制。

# 策略控制与行为优化

# 策略控制原理

强化学习中的策略控制可以转化为分类问题来理解：

  • 对于期望执行的行为：将真值标签设为 1，使用交叉熵损失
  • 对于不期望执行的行为：使用负交叉熵损失

训练数据的形式可以是：

  • 二元标签：{1, -1} 表示是否执行动作
  • 连续权重：用数值 A 表示执行动作的期望程度

# 策略梯度方法

策略梯度 (Policy Gradient) 是强化学习中的核心算法之一：

  1. 给智能体随机初始化参数
  2. 循环执行：
    • 使用当前参数收集交互数据
    • 计算优势值 A1,A2,…,ANA_1, A_2, \ldots, A_NA1​,A2​,…,AN​
    • 计算损失函数并更新参数

由于每次都需要重新收集数据，策略梯度方法的训练速度较慢

On-Policy vs Off-Policy

On-Policy 学习：智能体使用当前策略生成的数据来更新该策略。策略梯度方法是典型的 on-policy 算法，每次更新都需要用当前策略重新收集数据。

Off-Policy 学习：智能体可以使用其他策略 (如历史策略或探索策略) 生成的数据来更新当前策略。DQN 是典型的 off-policy 算法，可以重复使用经验回放池中的历史数据，提高样本效率。

# 探索机制

探索 (Exploration) 是强化学习的核心挑战，通过试错机制发现更优策略。平衡探索与利用是算法设计的关键。

# 深度强化学习算法

Deep Q-Network (DQN)

DQN 是深度强化学习的开创性算法，将深度神经网络与 Q 学习结合：

  • 使用神经网络逼近 Q 函数：Q(s,a;θ)Q(s,a;\theta)Q(s,a;θ)
  • 引入经验回放 (Experience Replay) 提高样本效率
  • 使用目标网络 (Target Network) 稳定训练过程
  • 属于 off-policy 算法，可重复利用历史经验

核心更新公式：

Q(s,a)←Q(s,a)+α[r+γmax⁡a′Q(s′,a′)−Q(s,a)]Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma \max_{a'} Q(s',a') - Q(s,a)]Q(s,a)←Q(s,a)+α[r+γa′max​Q(s′,a′)−Q(s,a)]

  • 状态价值函数：V(s)V(s)V(s) - 评估状态本身的价值
  • 优势函数：A(s,a)A(s,a)A(s,a) - 评估动作相对于平均水平的优势

这种分解有助于更好地学习状态价值，特别是在动作空间较大的情况下。

Proximal Policy Optimization (PPO)

PPO 是目前最流行的策略优化算法之一：

  • 解决策略梯度方法中的策略更新步长问题
  • 引入重要性采样和裁剪机制限制策略变化幅度
  • 在策略更新的稳定性和样本效率间取得良好平衡

# 特殊挑战与解决方案

# 稀疏奖励问题

稀疏奖励 (Sparse Reward) 是强化学习面临的主要挑战，即大部分时间步的奖励 rt=0r_t = 0rt​=0。

解决方案包括：

# 奖励塑形

定义额外的辅助奖励来引导智能体学习，但需要避免改变最优策略。

# 模仿学习

模仿学习 (Imitation Learning) 利用专家演示数据，让智能体直接学习专家的行为模式。

# 逆强化学习

逆强化学习 (Inverse Reinforcement Learning) 通过观察专家行为来学习奖励函数：

  1. 初始化智能体，与环境交互产生轨迹
  2. 设计奖励函数，使专家轨迹获得更高分数
  3. 智能体优化这个学习到的奖励函数
Random Interest Graph (RIG)

RIG 是一种用于稀疏奖励环境的探索方法：

  • 构建状态间的兴趣图，识别具有探索价值的状态
  • 通过随机游走和好奇心驱动的机制进行有效探索
  • 特别适用于大型离散状态空间的探索问题

该方法通过维护状态访问统计和状态间转移关系，引导智能体向未充分探索的区域前进。
