# Adapter Tuning 方法

Adapter Tuning 即在模型中添加 Adapter 层，在微调时冻结原参数，仅更新 Adapter 层。具体而言，其在预训练模型每层中插入用于下游任务的参数，即 Adapter 模块，在微调时冻结模型主体，仅训练特定于任务的参数。

# 结构设计原理

每个 Adapter 模块由两个前馈子层组成，第一个前馈子层将 Transformer 块的输出作为输入，将原始输入维度ddd 投影到mmm，通过控制mmm 的大小来限制 Adapter 模块的参数量，通常情况下m≪dm \ll dm≪d。在输出阶段，通过第二个前馈子层还原输入维度，将mmm 重新投影到ddd，作为 Adapter 模块的输出。

LoRA 事实上就是一种改进的 Adapter Tuning 方法。但 Adapter Tuning 方法存在推理延迟问题，由于增加了额外参数和额外计算量，导致微调之后的模型计算速度相较原预训练模型更慢。

# Prefix Tuning 方法

Prefix Tuning 方法固定预训练 LM，为 LM 添加可训练，任务特定的前缀，这样就可以为不同任务保存不同的前缀，微调成本也小。具体而言，在每一个输入 token 前构造一段与下游任务相关的 virtual tokens 作为 prefix，在微调时只更新 prefix 部分的参数，而其他参数冻结不变。

Prefix Tuning变体技术

目前常用的微量微调方法 P-tuning，其实就是 Prefix Tuning 的一种改进。P-tuning 通过学习连续的 prompt embeddings 来适应下游任务，相比传统的 discrete prompt 更加灵活高效。

Prefix Tuning 也存在固定的缺陷：模型可用序列长度减少。由于加入了 virtual tokens，占用了可用序列长度，因此越高的微调质量，模型可用序列长度就越低。

# LoRA 方法的理论基础

# 本征秩概念

如果一个大模型是将数据映射到高维空间进行处理，这里假定在处理一个细分的小任务时，是不需要那么复杂的大模型的，可能只需要在某个子空间范围内就可以解决，那么也就不需要对全量参数进行优化了，我们可以定义当对某个子空间参数进行优化时，能够达到全量参数优化的性能的一定水平（如 90% 精度）时，那么这个子空间参数矩阵的秩就可以称为对应当前待解决问题的本征秩（intrinsic rank）。

本征秩的直观理解

"本征秩" 可以理解为矩阵真正的有效维度，它告诉我们数据里到底包含多少 "有用的方向"。例如，在一个 1000 维的空间中，实际上可能只有 50 个方向包含了重要信息，那么本征秩就是 50。这个概念为 LoRA 的低秩分解提供了理论依据。

# 权重矩阵的低秩特性

预训练模型本身就隐式地降低了本征秩，当针对特定任务进行微调后，模型中权重矩阵其实具有更低的本征秩（intrinsic rank）。同时，越简单的下游任务，对应的本征秩越低。因此，权重更新的那部分参数矩阵尽管随机投影到较小的子空间，仍然可以有效的学习，可以理解为针对特定的下游任务这些权重矩阵就不要求满秩。

我们可以通过优化密集层在适应过程中变化的秩分解矩阵来间接训练神经网络中的一些密集层，从而实现仅优化密集层的秩分解矩阵来达到微调效果。

# LoRA 数学形式

假设预训练参数为θ0∈RD\theta_0 \in \mathbb{R}^Dθ0​∈RD，在特定下游任务上密集层权重参数矩阵对应的本征秩为θd\theta_dθd​，对应特定下游任务微调参数为θ∈RD\theta \in \mathbb{R}^Dθ∈RD，那么有：

θ=θ0+θd⋅M\theta = \theta_0 + \theta_d \cdot Mθ=θ0​+θd​⋅M

这个MMM 即为 LoRA 优化的秩分解矩阵。

# 低秩参数化更新矩阵

LoRA 假设权重更新的过程中也有一个较低的本征秩，对于预训练的权重参数矩阵W0∈Rd×kW_0 \in \mathbb{R}^{d \times k}W0​∈Rd×k（ddd 为上一层输出维度，kkk 为下一层输入维度），使用低秩分解来表示其更新：

W0+ΔW=W0+BAwhereB∈Rd×r,A∈Rr×kW_0 + \Delta W = W_0 + BA \quad \text{where} \quad B \in \mathbb{R}^{d \times r}, A \in \mathbb{R}^{r \times k}W0​+ΔW=W0​+BAwhereB∈Rd×r,A∈Rr×k

在训练过程中，W0W_0W0​ 冻结不更新，AAA、BBB 包含可训练参数。

因此，LoRA 的前向传递函数为：

h=W0x+ΔWx=W0x+BAxh = W_0 x + \Delta W x = W_0 x + B A xh=W0​x+ΔWx=W0​x+BAx

在开始训练时，对AAA 使用随机高斯初始化，对BBB 使用零初始化，然后使用 Adam 进行优化。

# Transformer 中的应用策略

在 Transformer 结构中，LoRA 技术主要应用在注意力模块的四个权重矩阵：WqW_qWq​、WkW_kWk​、WvW_vWv​、WoW_oWo​，而冻结 MLP 的权重矩阵。

通过消融实验发现同时调整WqW_qWq​ 和WvW_vWv​ 会产生最佳结果。

在上述条件下，可训练参数个数为：

Θ=2×LLoRA×dmodel×r\Theta = 2 \times L_{LoRA} \times d_{model} \times rΘ=2×LLoRA​×dmodel​×r

其中，LLoRAL_{LoRA}LLoRA​ 为应用 LoRA 的权重矩阵的个数，dmodeld_{model}dmodel​ 为 Transformer 的输入输出维度，rrr 为设定的 LoRA 秩。

一般情况下，rrr 取到 4、8、16。秩越小，参数量越少，但表达能力也相应降低。

# PEFT 库实现 LoRA 微调

PEFT库介绍

PEFT（Parameter-Efficient Fine-Tuning）是 Hugging Face 推出的参数高效微调库，提供了多种高效微调方法的统一接口，包括 LoRA、AdaLoRA、Prefix Tuning、P-Tuning v2 等。它能够显著降低微调所需的计算资源和存储空间，同时保持良好的性能。

# 基础配置与模型加载

LoRA参数详解
  • r: LoRA 的秩，决定了低秩分解矩阵的维度，通常取 4、8、16
  • lora_alpha: LoRA 的缩放参数，用来平衡学习新任务的强度和保持原模型知识，通常设置为秩的 2-4 倍
  • lora_dropout: dropout 比例，防止过拟合
  • target_modules: 指定要应用 LoRA 的模块，不同模型可能需要手动指定

对不同的模型，LoRA 参数可能有所区别。例如，对于 ChatGLM，无需指定 target_modules，peft 可以自行找到；对于 BaiChuan，就需要手动指定。task_type 是模型的任务类型，大模型一般都是 CAUSAL_LM 即传统语言模型。

# 适用场景与限制

  • 下游任务适配和领域迁移
  • 多任务学习中的任务特化
  • 资源受限环境下的模型微调
  • 需要快速切换不同任务的应用场景
  • 知识注入类任务效果有限
  • 不适合模型预训练或大规模后训练
  • 对于需要学习全新知识的任务可能表现不佳

如果是应用在 DPO、KTO 上，则也相同的加入 LoRA 参数并通过 get_peft_model 获取一个 LoRA 模型即可，其他的不需要进行任何修改。但要注意的是，LoRA 微调能够大幅度降低显卡占用，且在下游任务适配上能够取得较好的效果，但如果是需要学习对应知识的任务，LoRA 由于只调整低秩矩阵，难以实现知识的注入，一般效果不佳，因此不推荐使用 LoRA 进行模型预训练或后训练。
