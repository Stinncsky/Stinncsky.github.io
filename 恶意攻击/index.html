# 对抗性攻击基础

对抗性攻击是指通过对输入数据添加精心设计的微小扰动来欺骗机器学习模型的技术。这种攻击利用了深度学习模型的脆弱性，即使是人眼无法察觉的噪声也可能导致模型产生错误的预测结果。

对抗性攻击的核心概念

对抗性攻击基于一个重要发现：深度学习模型虽然在正常数据上表现优异，但对输入的微小变化极其敏感。攻击者可以利用这一特性，通过梯度信息找到最有效的扰动方向，从而以最小的修改代价实现攻击目标。这种脆弱性不仅存在于图像识别领域，在自然语言处理、语音识别等多个 AI 应用场景中都有体现。

对抗性攻击的核心思想：给输入加入噪音，使模型产生错误输出

# 攻击类型分类

# 无目标攻击

无目标攻击的目标是让模型的输出与原始预测结果不同，而不关心具体的错误分类结果。

设原始输入为 x0x^0x0，对应的真实标签为 y0=f(x0)y^0 = f(x^0)y0=f(x0)。无目标攻击寻找一个对抗样本 xxx，使得模型预测 y=f(x)y = f(x)y=f(x) 与真实标签 y^\hat{y}y^​ 尽可能远离：

L(x)=−e(y,y^)L(x) = -e(y, \hat{y})L(x)=−e(y,y^​)

其中 e(⋅,⋅)e(\cdot, \cdot)e(⋅,⋅) 是损失函数（如交叉熵损失）。

约束优化问题表示为：

x∗=arg⁡min⁡d(x0,x)≤ϵL(x)x^* = \arg \min_{d(x^0, x) \leq \epsilon} L(x)x∗=argd(x0,x)≤ϵmin​L(x)

无目标攻击的应用场景

无目标攻击常用于测试模型的整体鲁棒性。在实际应用中，这类攻击可能导致自动驾驶系统错误识别交通标志，或使人脸识别系统无法正确识别用户身份。由于不需要指定特定的错误类别，无目标攻击相对容易实现，但对系统造成的威胁程度可能不如有目标攻击精确。

# 有目标攻击

有目标攻击不仅要使模型预测错误，还要将输出引导至攻击者指定的目标类别。

损失函数修改为：

L(x)=−e(y,y^)+e(y,ytarget)L(x) = -e(y, \hat{y}) + e(y, y^{\text{target}})L(x)=−e(y,y^​)+e(y,ytarget)

其中 ytargety^{\text{target}}ytarget 是攻击者指定的目标标签。

有目标攻击的威胁性

有目标攻击的危险性更高，因为攻击者可以精确控制模型的错误行为。例如，在医疗影像诊断中，攻击者可能将恶性肿瘤的影像伪装成良性，导致严重的误诊。在金融领域，有目标攻击可能使欺诈检测系统将可疑交易误判为正常交易。

# 距离度量与扰动限制

对抗性攻击的一个关键约束是扰动的大小必须足够小，以保持对抗样本的隐蔽性。常用的距离度量包括：

# L2 范数距离

d(x0,x)=∣∣Δx∣∣2=∑i(Δxi)2d(x^0, x) = ||\Delta x||_2 = \sqrt{\sum_i (\Delta x_i)^2}d(x0,x)=∣∣Δx∣∣2​=i∑​(Δxi​)2​

L2 范数衡量的是欧几里得距离，适合描述整体的扰动强度。

# L∞范数距离

d(x0,x)=∣∣Δx∣∣∞=max⁡i∣Δxi∣d(x^0, x) = ||\Delta x||_\infty = \max_i |\Delta x_i|d(x0,x)=∣∣Δx∣∣∞​=imax​∣Δxi​∣

L∞范数关注的是单个像素的最大变化量。

对于图像数据，L∞范数更符合人类的视觉感知特性

不同范数的应用考量

选择合适的距离度量对攻击效果至关重要。L2 范数倾向于产生分布较为均匀的小幅扰动，而 L∞范数则确保没有任何像素的变化超过阈值。在实际应用中，L∞范数在图像攻击中更受青睐，因为它直接对应了人眼对亮度变化的敏感度阈值。

# FGSM 算法

快速梯度符号方法（Fast Gradient Sign Method）是最经典的单步攻击算法。

FGSM算法原理

FGSM 由 Ian Goodfellow 在 2015 年提出，是第一个实用的对抗性攻击算法。该算法的核心思想是利用损失函数关于输入的梯度方向，以最大的步长朝着增加损失的方向移动。虽然简单，但 FGSM 揭示了深度学习模型的根本脆弱性，并为后续的攻击和防御研究奠定了基础。

算法步骤：

  1. 计算损失函数关于输入的梯度：g=∇xL(x,y)g = \nabla_x L(x, y)g=∇x​L(x,y)
  2. 对梯度进行符号化处理：\text{sign}(g_i) = \begin{cases} 1 & \text{if } g_i > 0 \\ -1 & \text{if } g_i \leq 0 \end
  3. 生成对抗样本：xadv=x+ϵ⋅sign(g)x_{\text{adv}} = x + \epsilon \cdot \text{sign}(g)xadv​=x+ϵ⋅sign(g)

# 黑盒攻击策略

黑盒攻击是指攻击者无法获取目标模型内部信息，只能通过输入输出接口进行攻击。

# 代理模型攻击

如果攻击者了解目标模型的训练数据，可以训练一个代理模型来模拟目标模型的行为，然后在代理模型上生成对抗样本。

代理模型的迁移性

对抗样本的一个重要特性是跨模型迁移性。在一个模型上生成的对抗样本往往对其他具有相似架构或训练数据的模型也有效。这种迁移性使得黑盒攻击成为可能，但也意味着单纯依靠模型保密无法有效防御对抗性攻击。

# 数据收集与模拟

当无法获取原始训练数据时，攻击者可以通过以下方式收集数据：

  1. 查询目标模型：反复输入不同样本，收集输入输出对
  2. 数据增强：对收集到的少量数据进行变换扩充
  3. 生成对抗网络：使用 GAN 生成与真实数据分布相似的样本

# 集成攻击

集成攻击（Ensemble Attack）使用多个不同架构的代理模型来提高攻击的迁移性：

其中 LiL_iLi​ 是第 iii 个代理模型的损失函数，wiw_iwi​ 是对应的权重。

# 特殊攻击技术

# One Pixel Attack

单像素攻击证明了仅修改图像中的一个像素就可能欺骗深度学习模型。

单像素攻击的意义

单像素攻击虽然在实际应用中成功率相对较低，但它揭示了一个令人震惊的事实：即使是最微小的修改也可能导致模型失效。这种攻击通常使用进化算法或差分进化来搜索最优的像素位置和颜色值，展示了对抗性攻击的极端可能性。

# Universal Adversarial Attack

通用对抗攻击寻找一个固定的扰动模式，该模式对大多数输入样本都有效：

Ex∼D[P(f(x+δ)≠f(x))]≥1−α\mathbb{E}_{x \sim \mathcal{D}}[\mathbb{P}(f(x + \delta) \neq f(x))] \geq 1 - \alphaEx∼D​[P(f(x+δ)=f(x))]≥1−α

其中 δ\deltaδ 是通用扰动，α\alphaα 是容错率。

# 物理世界攻击

物理世界攻击将对抗样本从数字域扩展到现实世界，需要考虑：

  • 光照变化：不同光照条件下的鲁棒性
  • 视角变化：从不同角度观察的一致性
  • 打印失真：数字到物理转换的误差

# 对抗性重编程

对抗性重编程（Adversarial Reprogramming）通过添加特定的输入扰动，使预训练模型执行与原始任务完全不同的新任务。

对抗性重编程的威胁

这种攻击方式特别危险，因为它可以将一个正常的模型 "劫持" 用于恶意目的。例如，攻击者可能将一个图像分类模型重编程为垃圾邮件检测器，或将语音识别系统改造为恶意命令执行器。这种攻击揭示了 AI 系统的一个根本性安全问题。

# 后门攻击

后门攻击通过在训练阶段向数据集中注入恶意样本来实现攻击目标。

# 训练集投毒

攻击者在训练数据中插入带有特定触发器（trigger）的样本：

  1. 触发器设计：选择小的、不显眼的模式作为触发器
  2. 标签修改：将带有触发器的样本标记为目标类别
  3. 混合训练：将投毒样本与正常样本混合训练

后门攻击在模型正常使用时不会被发现，只有在输入包含特定触发器时才会激活

# 输入预处理

通过对输入进行预处理来移除潜在的对抗性扰动：

使用各种滤波器（如高斯滤波、中值滤波）来平滑输入，减少高频噪声的影响。

训练一个去噪自编码器或生成对抗网络来重构输入，移除对抗性扰动。

在输入中添加随机噪声或进行随机变换，破坏对抗样本的精确性。

# 对抗性训练

对抗性训练是目前最有效的防御方法，通过在训练过程中加入对抗样本来提高模型鲁棒性：

min⁡θE(x,y)∼D[max⁡∣∣δ∣∣∞≤ϵL(fθ(x+δ),y)]\min_\theta \mathbb{E}_{(x,y) \sim \mathcal{D}} \left[ \max_{||\delta||_\infty \leq \epsilon} L(f_\theta(x + \delta), y) \right]θmin​E(x,y)∼D​[∣∣δ∣∣∞​≤ϵmax​L(fθ​(x+δ),y)]

对抗性训练的局限性

虽然对抗性训练能显著提高模型的鲁棒性，但它也存在一些问题：1）计算开销大，训练时间显著增加；2）可能无法防御新的、未见过的攻击方法；3）在提高鲁棒性的同时可能降低在干净数据上的准确率；4）需要预先设定扰动的类型和强度，难以覆盖所有可能的攻击场景。

# 认证防御

认证防御方法为模型的预测提供数学保证，确保在一定扰动范围内预测结果不变：

  • 区间界限传播：计算神经网络每层输出的上下界
  • 线性规划松弛：将神经网络的验证问题转化为线性规划问题
  • 随机平滑：通过添加高斯噪声并平均多次预测来提供概率保证

认证防御虽然计算复杂，但能提供理论保证，是对抗性机器学习的重要研究方向
