# GAN 基本原理与架构

生成对抗网络（GAN）是一种深度学习模型，通过两个神经网络的对抗训练来学习数据分布。其核心思想是将网络用作生成器，输入形式为 x+z→network→yx + z \rightarrow \text{network} \rightarrow yx+z→network→y，其中 zzz 来自简单的分布，每次输入时 zzz 的值是随机的，从而使输出 yyy 成为一个复杂的分布。

这种随机性赋予了模型 "创造力"，即同样的输入可以产生多种不同的输出。

什么是分布生成

传统的网络是确定性映射：给定输入 x，总是产生相同的输出 y。而生成器网络通过引入随机变量 z，能够输出一个分布而非单一值。这使得模型能够生成多样化的内容，具备了创造性。

# 生成器与判别器架构

生成器（Generator）：接受随机噪声 zzz 作为输入，生成逼真的假数据。对于无条件生成，其映射关系为：

z→Generator→yz \rightarrow \text{Generator} \rightarrow yz→Generator→y

判别器（Discriminator）：作为一个神经网络分类器，输出一个标量值，大值表示真实数据，小值表示虚假数据。

# 训练流程

GAN 采用交替训练策略：

  1. 固定生成器 G，更新判别器 D：训练判别器区分真实数据和生成数据
  2. 固定判别器 D，更新生成器 G：训练生成器欺骗判别器
为什么需要交替训练

如果同时更新两个网络，会导致训练不稳定。交替训练确保在每个阶段都有一个明确的优化目标：判别器学习更好地区分真假，生成器学习更好地骗过判别器。

# GAN 的理论基础

# 目标函数与 JS 散度

GAN 的核心目标是让生成的数据分布 PGP_GPG​ 尽可能接近真实数据分布 PdataP_{data}Pdata​。原始 GAN 的目标函数为：

JS散度的定义

JS 散度（Jensen-Shannon Divergence）是衡量两个概率分布相似度的指标，定义为：

JS(P∣∣Q)=12DKL(P∣∣M)+12DKL(Q∣∣M)\text{JS}(P||Q) = \frac{1}{2}D_{KL}(P||M) + \frac{1}{2}D_{KL}(Q||M)JS(P∣∣Q)=21​DKL​(P∣∣M)+21​DKL​(Q∣∣M)

其中 M=12(P+Q)M = \frac{1}{2}(P+Q)M=21​(P+Q)，DKLD_{KL}DKL​ 是 KL 散度。JS 散度具有对称性和有界性。

# JS 散度的局限性

JS 散度在 GAN 训练中存在重要缺陷，这是原始 GAN 难以训练的根本原因。

JS 散度不适合 GAN 的主要原因：

  1. 高维空间中的低维流形：PGP_GPG​ 和 PdataP_{data}Pdata​ 都是高维空间中的低维流形
  2. 采样不充分：有限样本导致两个分布的重合区域很少
  3. JS 散度特性：当两个分布无重合时，JS 散度值恒为 log⁡2\log 2log2，梯度为零

# Wasserstein GAN 及其改进

# WGAN 基本思想

WGAN 使用 Wasserstein 距离替代 JS 散度来衡量分布差异：

W(Pdata,PG)=inf⁡γ∈Π(Pdata,PG)E(x,y)∼γ[∣∣x−y∣∣]W(P_{data}, P_G) = \inf_{\gamma \in \Pi(P_{data}, P_G)} \mathbb{E}_{(x,y) \sim \gamma}[||x-y||]W(Pdata​,PG​)=γ∈Π(Pdata​,PG​)inf​E(x,y)∼γ​[∣∣x−y∣∣]

Wasserstein距离

Wasserstein 距离（又称 Earth Mover's Distance）衡量将一个分布 "搬运" 成另一个分布的最小代价。即使两个分布没有重合，Wasserstein 距离仍能提供有意义的梯度信息。

根据 Kantorovich-Rubinstein 定理，Wasserstein 距离可以表示为：

W(Pdata,PG)=sup⁡∣∣f∣∣L≤1Ex∼Pdata[f(x)]−Ex∼PG[f(x)]W(P_{data}, P_G) = \sup_{||f||_L \leq 1} \mathbb{E}_{x \sim P_{data}}[f(x)] - \mathbb{E}_{x \sim P_G}[f(x)]W(Pdata​,PG​)=∣∣f∣∣L​≤1sup​Ex∼Pdata​​[f(x)]−Ex∼PG​​[f(x)]

其中 fff 必须满足 1-Lipschitz 约束。

# WGAN 的 Lipschitz 约束实现

原始 WGAN 方法：使用权重裁剪（Weight Clipping），将判别器权重限制在 [−c,c][-c, c][−c,c] 范围内。

改进方法：

在损失函数中添加梯度惩罚项：

L=E[D(xreal)]−E[D(xfake)]+λE[(∥∇x^D(x^)∥2−1)2]L = \mathbb{E}[D(x_{real})] - \mathbb{E}[D(x_{fake})] + \lambda \mathbb{E}[(\|\nabla_{\hat{x}} D(\hat{x})\|_2 - 1)^2]L=E[D(xreal​)]−E[D(xfake​)]+λE[(∥∇x^​D(x^)∥2​−1)2]

其中 x^\hat{x}x^ 是真实样本和生成样本之间的插值点。

通过谱归一化来控制神经网络的 Lipschitz 常数，确保判别器的梯度接近 1。这种方法计算效率更高，训练更稳定。

谱归一化原理

谱归一化通过除以权重矩阵的最大奇异值来约束每层的 Lipschitz 常数。对于权重矩阵 W，谱归一化后的权重为：

Wˉ=Wσ(W)\bar{W} = \frac{W}{\sigma(W)}Wˉ=σ(W)W​

其中 σ(W)\sigma(W)σ(W) 是 W 的谱半径（最大奇异值）。

# GAN 训练的挑战与问题

# 训练不稳定性

GAN 训练面临多个挑战：

  1. 更新频率不平衡：实际训练中判别器更新次数远少于生成器
  2. 相互依赖性：当生成器或判别器中任一个停止改进时，另一个也会停止
  3. 离散输出限制：GAN 难以直接生成文本，因为微小的分数变化可能不会改变离散的输出结果

# 模式坍塌与模式丢失

生成器只学会生成少数几种样本模式，忽略数据分布的多样性。表现为生成的样本缺乏多样性，大部分样本都很相似。

生成器完全忽略真实数据分布中的某些模式，导致生成的样本无法覆盖完整的数据分布。与模式坍塌不同，这是整个模式的缺失。

模式问题的根本原因

模式坍塌和模式丢失的根本原因是 GAN 的目标函数设计。生成器只需要生成能够欺骗判别器的样本，而不需要覆盖完整的数据分布。这导致生成器可能 "取巧" 地只生成容易的样本类型。

# GAN 评估指标

# Inception Score (IS)

Inception Score 评估生成图像的质量和多样性：

IS=exp⁡(Ex∼PG[DKL(p(y∣x)∣∣p(y))])\text{IS} = \exp(\mathbb{E}_{x \sim P_G}[D_{KL}(p(y|x) || p(y))])IS=exp(Ex∼PG​​[DKL​(p(y∣x)∣∣p(y))])

IS计算原理

IS 使用预训练的 Inception 网络计算条件标签分布 p (y|x) 和边缘分布 p (y) 之间的 KL 散度。高质量的生成样本应该有清晰的类别预测（低条件熵）和多样的类别分布（高边缘熵）。

# Fréchet Inception Distance (FID)

FID 通过比较真实数据和生成数据在 Inception 网络特征空间中的分布来评估质量：

FID=∣∣μreal−μfake∣∣2+Tr(Σreal+Σfake−2(ΣrealΣfake)1/2)\text{FID} = ||\mu_{real} - \mu_{fake}||^2 + \text{Tr}(\Sigma_{real} + \Sigma_{fake} - 2(\Sigma_{real}\Sigma_{fake})^{1/2})FID=∣∣μreal​−μfake​∣∣2+Tr(Σreal​+Σfake​−2(Σreal​Σfake​)1/2)

FID 值越低表示生成质量越好，它能更好地捕捉生成样本的多样性和质量。

# 条件生成与应用扩展

# 条件 GAN

条件生成要求生成器同时接收条件输入 xxx 和随机噪声 zzz：

x+z→G→yx + z \rightarrow G \rightarrow yx+z→G→y

判别器需要同时考虑输入 xxx 和输出 yyy 的配对关系，这需要成对的训练数据和相应标注。

# 无监督域转换

对于无配对数据的域转换，可以使用无条件生成将原始分布替换为目标域的分布，但这无法保证输出与输入的对应关系。

# CycleGAN

CycleGAN 通过循环一致性约束解决无配对数据的域转换问题：

  • 双向生成器：GX→YG_{X \rightarrow Y}GX→Y​ 和 G_
  • 循环一致性损失：

    Lcyc=Ex[∣∣GY→X(GX→Y(x))−x∣∣1]L_{cyc} = \mathbb{E}_{x}[||G_{Y \rightarrow X}(G_{X \rightarrow Y}(x)) - x||_1]Lcyc​=Ex​[∣∣GY→X​(GX→Y​(x))−x∣∣1​]

    +Ey[∣∣GX→Y(GY→X(y))−y∣∣1]+ \mathbb{E}_{y}[||G_{X \rightarrow Y}(G_{Y \rightarrow X}(y)) - y||_1]+Ey​[∣∣GX→Y​(GY→X​(y))−y∣∣1​]

CycleGAN原理

CycleGAN 的核心假设是：如果图像从域 X 转换到域 Y，再从域 Y 转换回域 X，应该能够重建原始图像。这种循环一致性约束虽然不能保证学到完全正确的转换，但在实践中效果良好。

# StarGAN

StarGAN 扩展了域转换的概念，使用单一生成器实现多域转换：

G(x,c)→yG(x, c) \rightarrow yG(x,c)→y

其中 ccc 是域标签，判别器不仅要判断真假，还要预测域标签。

StarGAN优势

与需要为每对域训练单独生成器的方法相比，StarGAN 只需要一个生成器就能处理多个域之间的转换，大大减少了模型复杂度和训练成本。
