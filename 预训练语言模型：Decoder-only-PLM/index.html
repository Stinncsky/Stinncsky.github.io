# Decoder-Only 架构基础

Decoder-Only 是目前大语言模型（LLM）的基础架构。目前所有主流 LLM 基本都采用 Decoder-Only 模型（RWKV、Mamba 等非 Transformer 架构除外）。引发 LLM 热潮的 ChatGPT，正是 Decoder-Only 系列的代表模型 GPT 系列的大成之作。目前作为开源 LLM 基本架构的 LLaMA 模型，也是在 GPT 模型架构基础上优化发展而来。

Decoder-Only 架构通过掩码自注意力机制实现文本的自回归生成，是目前最成功的 LLM 架构范式。

# GPT 模型架构详解

# 输入处理与编码

输入的 input_ids 首先通过 Embedding 层，再经过 Positional Embedding 进行位置编码。不同于 BERT 选择可训练的全连接层作为位置编码，GPT 沿用了 Transformer 的经典 Sinusoidal 位置编码，即通过三角函数进行绝对位置编码。

Sinusoidal 位置编码原理

Sinusoidal 位置编码使用不同频率的正弦和余弦函数来为每个位置生成唯一的编码向量。对于位置 pospospos 和维度 iii，编码公式为：

PE(pos,2i)=sin⁡(pos/100002i/dmodel)PE_{(pos,2i)} = \sin(pos/10000^{2i/d_{model}})PE(pos,2i)​=sin(pos/100002i/dmodel​)

PE(pos,2i+1)=cos⁡(pos/100002i/dmodel)PE_{(pos,2i+1)} = \cos(pos/10000^{2i/d_{model}})PE(pos,2i+1)​=cos(pos/100002i/dmodel​)

其中 dmodeld_{model}dmodel​ 是模型的隐藏维度。这种编码方式的优势在于能够处理任意长度的序列，且相对位置关系具有一定的规律性。

# Decoder 层结构

通过 Embedding 层和 Positional Embedding 层编码成 hidden_states 之后，进入解码器（Decoder）。第一代 GPT 模型选择了 12 层解码器层，但在解码器层内部，相较于 Transformer 原始 Decoder 层的双注意力层设计，GPT 的 Decoder 层更像 Encoder 层。

由于不再有 Encoder 的编码输入，Decoder 层仅保留了一个带掩码的注意力层，并将 LayerNorm 层从 Transformer 的注意力层之后提到了注意力层之前。 hidden_states 输入 Decoder 层后的处理流程：

  1. 预归一化：先进行 LayerNorm
  2. 掩码注意力计算：进行掩码自注意力计算
  3. 残差连接：与输入进行残差连接
  4. 再次归一化：再一次 LayerNorm
  5. MLP 处理：进入 MLP 层并得到最后输出
掩码自注意力机制

由于不存在 Encoder 的编码结果，Decoder 层中的掩码注意力也是自注意力计算。对一个输入的 hidden_states ，会通过三个参数矩阵来生成 query、key 和 value，而不再是像 Transformer 中的 Decoder 那样由 Encoder 输出作为 key 和 value。

后续的注意力计算过程与 BERT 类似，只是在计算得到注意力权重之后，通过掩码矩阵来遮蔽未来 token 的注意力权重，从而限制每一个 token 只能关注到它之前 token 的注意力，实现掩码自注意力的计算。

GPT 的 MLP 层选择了两个一维卷积核来提取特征，而非线性矩阵，不过从效果上说两者差异不大。通过 N 个 Decoder 层后的 hidden_states 最后经过线性矩阵映射到词表维度，转化成自然语言的 token，从而生成目标序列。

# 因果语言模型预训练任务

Decoder-Only 的模型结构更适合文本生成任务，因此选择了最传统也最直接的预训练任务 —— 因果语言模型（Causal Language Model，CLM）。

CLM 可以看作 N-gram 语言模型的直接扩展。N-gram 语言模型是基于前 N 个 token 来预测下一个 token，CLM 则是基于一个自然语言序列的前面所有 token 来预测下一个 token，通过不断重复该过程来实现目标文本序列的生成。

N-gram 语言模型

N-gram 语言模型是一种基于统计的语言模型，通过统计语料库中 N 个连续词语的出现频率来预测下一个词。例如，bigram（N=2）模型根据前一个词来预测当前词，trigram（N=3）模型根据前两个词来预测当前词。其核心假设是当前词只依赖于前 N-1 个词，这种马尔可夫假设大大简化了计算复杂度。

CLM 的自回归特性使得模型只能看到当前位置之前的信息，这是通过掩码注意力机制实现的关键约束。

# LLaMA 模型架构

与 GPT 类似，LLaMA 模型的处理流程也始于将输入文本通过 tokenizer 进行编码，转化为一系列的 input_ids 。这些 input_ids 经过 embedding 层和 positional embedding 层的结合，形成了包含语义和位置信息的 hidden_states 。

# Decoder Block 处理流程

hidden_states 被输入到模型的 decoder 层，经历由多个 decoder block 组成的处理：

# 1. Masked Self-Attention 层

在每个 decoder block 内部，首先是 masked self-attention 层：

  1. 向量计算：分别计算 query、key 和 value 三个向量，通过 hidden_states 线性变换得到
  2. 注意力分数：使用 softmax 函数计算 attention score，反映不同位置间的关联强度
  3. 加权输出：将 value 向量与 attention score 相乘，得到加权后的 attention 结果
MQA 注意力机制

Multi-Query Attention（MQA）是一种优化的注意力机制，与传统的 Multi-Head Attention（MHA）不同。在 MHA 中，每个注意力头都有独立的 query、key 和 value 参数矩阵；而在 MQA 中，所有注意力头共享相同的 key 和 value 参数，只有 query 参数是独立的。

这种设计显著减少了参数量和内存占用，特别是在推理阶段，可以大幅提升计算效率。MQA 在保持模型性能的同时，实现了更好的推理速度和内存效率的平衡。

# 2. MLP 层处理

完成 masked self-attention 后， hidden_states 进入 MLP 层：

  1. 特征映射：第一个全连接层将 hidden_states 映射到中间维度
  2. 非线性变换：通过激活函数进行非线性变换，增加模型的非线性能力
  3. 维度还原：第二个全连接层将特征映射回原始的 hidden_states 维度

# 3. 最终输出生成

经过多个 decoder block 的处理， hidden_states 通过线性层进行最终映射，输出维度与词表维度相同。模型根据 hidden_states 生成目标序列的概率分布，通过采样或贪婪解码等方法生成最终输出序列。

# GLM 模型的创新设计

GLM 在整体模型结构上与 GPT 大致类似，均是 Decoder-Only 结构，但有三点关键差异：

# 结构差异对比

GLM 使用 Post Norm：先完成残差计算，再进行 LayerNorm 计算

GPT/LLaMA 使用 Pre Norm：先进行 LayerNorm 计算，再进行残差计算

Post Norm 对参数正则化效果更强，模型鲁棒性更好；Pre Norm 可以防止梯度爆炸或消失，对大体量模型效果更好。

GLM：使用单个线性层实现最终 token 预测

GPT：使用 MLP 进行最终预测

GLM 的设计更加简单鲁棒，减少最终输出参数量，将更多参数分配给模型本身。

GLM：使用 GeLU 激活函数

GPT：使用 ReLU 激活函数

GeLU 对接近 0 的正向传播做非线性映射，保证激活函数后的非线性输出具有连续性。

# GLM 预训练任务

GLM 的核心创新是提出的通用语言模型（General Language Model）任务，结合了自编码思想和自回归思想的预训练方法：

  • 自编码思想：类似 MLM 任务，在输入文本中随机删除连续的 tokens，要求模型学习被删除的 tokens
  • 自回归思想：类似传统 CLM 任务，要求模型按顺序重建连续 tokens
GLM 预训练任务详解

GLM 通过优化自回归空白填充任务来实现 MLM 与 CLM 思想的结合。其核心思想是：

  1. 掩码策略：对输入序列进行随机掩码，但遮蔽的是连续的 token 序列而非单个 token
  2. 双重学习：模型既需要使用遮蔽部分的上下文预测遮蔽部分，又需要在遮蔽部分内部以 CLM 方式完成被遮蔽 tokens 的预测
  3. 统一框架：这种设计使得模型既能处理理解类任务（通过上下文预测），又能处理生成类任务（通过自回归生成）

这种统一的预训练方式使得 GLM 在理解和生成任务上都表现优异。

# 相关训练技术

现代 Decoder-Only 模型的成功还依赖于多种先进的训练技术：

SFT（Supervised Fine-Tuning）

SFT 是指监督微调，是大语言模型训练流程中的重要环节。在预训练完成后，模型通过在高质量的指令 - 回答数据集上进行监督学习，学会遵循人类指令并生成有用的回答。

SFT 的核心是使用精心构造的指令数据集，包含多样化的任务类型和高质量的标准答案。通过这一阶段的训练，模型从一个单纯的文本续写工具转变为能够理解和执行复杂指令的智能助手。

RLHF（Reinforcement Learning from Human Feedback）

RLHF 是一种结合强化学习和人类反馈的训练方法，用于进一步优化模型的输出质量。训练流程包括：

  1. 奖励模型训练：使用人类标注的偏好数据训练一个奖励模型，学习人类的价值判断
  2. PPO 优化：使用 Proximal Policy Optimization 算法，根据奖励模型的反馈来优化语言模型的策略
  3. 迭代改进：通过多轮迭代，不断提升模型输出与人类偏好的一致性

RLHF 是 ChatGPT 等模型能够生成高质量、符合人类价值观输出的关键技术。

稀疏注意力机制

稀疏注意力机制是为了解决标准自注意力机制在长序列上计算复杂度过高的问题而提出的优化方案。标准注意力机制的计算复杂度为 O(n2)O(n^2)O(n2)，其中 nnn 是序列长度。

稀疏注意力通过限制每个位置只关注序列中的一个子集来降低计算复杂度，常见的稀疏模式包括：

  • 局部注意力：每个位置只关注其周围的固定窗口
  • 分块注意力：将序列分成块，每个位置只关注同一块内的其他位置
  • 全局 + 局部注意力：部分位置具有全局注意力，其他位置使用局部注意力

这些技术使得模型能够处理更长的输入序列，同时保持计算效率。
