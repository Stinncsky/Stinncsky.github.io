# 2. 核心组件实现

LLaMA2 的强大性能源于其精心设计的核心组件。下面我们逐一实现这些关键模块。

# 2.1 RMSNorm (Root Mean Square Normalization)

RMSNorm 是一种比 LayerNorm 更高效的归一化方法。它通过计算均方根来对输入进行缩放，省去了减去均值的操作，从而简化了计算。

# 2.2 旋转位置嵌入 (RoPE)

RoPE (Rotary Position Embedding) 是一种将绝对位置信息以相对方式编码的技术。它通过在注意力计算中旋转查询（Query）和键（Key）的嵌入向量来实现，使得模型能够更好地捕捉词元间的相对位置关系。

# 2.3 注意力机制 (Attention)

LLaMA2 的注意力机制融合了 分组查询注意力 (GQA) 和 Flash Attention，以实现高效的计算和推理。

GQA (Grouped-Query Attention)

定义: GQA 是一种介于多头注意力 (MHA) 和多查询注意力 (MQA) 之间的注意力机制。在 MHA 中，每个查询头（Query Head）都有自己独立的键 / 值头（Key/Value Head）。在 GQA 中，多个查询头被分在一组，共享同一组键 / 值头。

核心思想：通过让多组查询头共享键 / 值头，GQA 显著减少了推理过程中需要缓存的 K/V Cache 的大小，从而降低了内存带宽需求，加快了模型的生成速度。

应用：在我们的代码中， n_heads 代表总的查询头数量，而 n_kv_heads 代表键 / 值头的数量。 n_heads 和 n_kv_heads 的比值 n_rep 就是分组的大小。 repeat_kv 函数就是用来将 K 和 V 张量在头的维度上进行复制，以匹配查询头的数量。

Flash Attention

定义: Flash Attention 是一种 I/O 感知的精确注意力算法，它通过分块（Tiling）计算来优化 GPU 内存的使用。

核心思想：传统注意力机制需要生成一个巨大的 (seq_len, seq_len) 的注意力矩阵，这在序列很长时会消耗大量显存。Flash Attention 避免了完整地实例化这个矩阵，而是将计算过程拆分成多个小块，在 GPU 的高速 SRAM 中完成计算，大大减少了对 HBM（高带宽内存）的读写次数，从而实现了显著的速度提升和显存节省。

应用：在代码中，我们通过 hasattr(torch.nn.functional, 'scaled_dot_product_attention') 来检查 PyTorch 版本是否支持 Flash Attention。如果支持，就直接调用 F.scaled_dot_product_attention 并设置 is_causal=True 来启用。

# 2.4 前馈网络 (MLP)

LLaMA2 使用了带有 SwiGLU 激活函数的前馈网络。这种结构通过三个线性层实现，相比传统的 ReLU 激活函数能提供更好的性能。

# 3. 模型整体架构

我们将上述组件组合起来，构建完整的 Transformer 解码器层和最终的模型。

# 3.1 解码器层 (Decoder Layer)

每个解码器层包含一个注意力模块和一个前馈网络模块。输入会先经过 RMSNorm，然后进入注意力模块，其输出通过残差连接与原始输入相加。接着，结果再次经过 RMSNorm 和前馈网络，并再次与输入进行残差连接。

# 4.1 训练 Tokenizer

# 4.2 数据集准备

我们为预训练和指令微调（SFT）分别创建了 Dataset 类。

# 预训练数据集 (PretrainDataset)

预训练任务的目标是预测下一个词。损失函数在所有有效词元上计算。

# 5. 训练与微调

训练过程通过 argparse 接收命令行参数，实现了灵活的配置。关键技术包括混合精度训练、梯度累积和学习率调度。

混合精度训练 (Mixed-Precision Training)

定义：一种在训练过程中同时使用低精度（如 float16 或 bfloat16 ）和高精度（ float32 ）浮点数的策略。

核心思想:

  1. 前向 / 反向传播：大部分计算（如矩阵乘法）使用 float16 ，速度更快，显存占用更少。
  2. 权重更新：为了避免 float16 范围过小导致的梯度消失问题，优化器以 float32 格式存储和更新模型权重。
  3. 损失缩放 (Loss Scaling): 在反向传播前，将损失值乘以一个较大的缩放因子，以放大梯度，防止其因 float16 精度不足而变为零。在更新权重前再将梯度缩放回来。

应用：代码中通过 torch.cuda.amp.autocast 上下文管理器和 GradScaler 来自动实现混合精度训练。

SwanLab

定义：一个用于机器学习实验跟踪和可视化的工具，类似于 TensorBoard 或 Weights & Biases。

核心思想：通过在代码中插入简单的日志记录函数（如 swanlab.log() ），开发者可以将训练过程中的关键指标（如损失、学习率、准确率）和超参数实时发送到云端或本地服务器进行可视化，方便比较不同实验的效果、监控训练状态。

应用：在训练循环中，我们使用 swanlab.log({"loss": ..., "lr": ...}) 来记录每个步骤的损失和学习率。

使用 argparse 模块可以让我们从命令行方便地控制训练的各个方面，如批次大小、学习率、设备等。这是组织和复现实验的标准做法。

# 5.2 预训练 (Pre-training)

预训练脚本加载 PretrainDataset ，并在大规模无标签文本上训练模型，使其学习语言的基本规律。

# 5.3 指令微调 (SFT)

SFT 脚本加载预训练好的模型权重，并使用 SFTDataset 在有标签的对话数据上进行训练，使模型学会如何与用户交互。
