# 自监督学习基础概念

自监督学习是一种机器学习范式，通过将输入数据 xxx 分解为 x′x'x′ 和 x′′x''x′′ 两部分，其中 x′x'x′ 作为输入，x′′x''x′′ 作为预测目标，从而在无需人工标注的情况下学习数据的内在表示。

GLUE基准评测详解

GLUE (General Language Understanding Evaluation) 是一个用于评估自然语言理解模型的综合基准测试集，包含 9 个不同类型的任务：

  1. CoLA (Corpus of Linguistic Acceptability): 语法可接受性判断
  2. SST-2 (Stanford Sentiment Treebank): 情感分析
  3. MRPC (Microsoft Research Paraphrase Corpus): 释义识别
  4. STS-B (Semantic Textual Similarity Benchmark): 语义文本相似度
  5. QQP (Quora Question Pairs): 问题重复检测
  6. MNLI (Multi-Genre Natural Language Inference): 多类型自然语言推理
  7. QNLI (Question Natural Language Inference): 问答自然语言推理
  8. RTE (Recognizing Textual Entailment): 文本蕴含识别
  9. WNLI (Winograd Natural Language Inference): Winograd 自然语言推理

这些任务覆盖了语言理解的不同维度，为模型性能提供全面评估。

# 早期自监督学习模型：ELMo

ELMo (Embeddings from Language Models) 是最早的成功自监督学习模型之一。它通过双向语言模型训练，为每个词生成考虑上下文的动态词向量表示。

与传统静态词嵌入（如 Word2Vec）不同，ELMo 产生的是上下文化词嵌入 (contextualized word embedding)，即同一个词在不同句子中会有不同的向量表示。

CBOW模型原理

CBOW (Continuous Bag of Words) 是 Word2Vec 的一种训练方式，通过周围词汇预测中心词。给定上下文词汇 wt−n,...,wt−1,wt+1,...,wt+nw_{t-n}, ..., w_{t-1}, w_{t+1}, ..., w_{t+n}wt−n​,...,wt−1​,wt+1​,...,wt+n​，模型学习预测中心词 wtw_twt​。CBOW 适合处理小型数据集，训练速度较快，但对低频词的处理效果不如 Skip-gram 模型。

# BERT 及其训练策略

BERT (Bidirectional Encoder Representations from Transformers) 采用两种主要的预训练策略：

# 掩码语言建模 (Masked Language Model)

BERT 在训练时对输入文本进行掩码处理：

  • 随机选择 15% 的 token 进行掩码
  • 其中 80% 替换为 [MASK] 特殊标记
  • 10% 替换为随机 token
  • 10% 保持原词不变

模型需要基于上下文预测被掩码的原始词汇，损失函数为：

LMLM=−∑i∈Mlog⁡P(xi∣x^\M)L_{MLM} = -\sum_{i \in M} \log P(x_i | \hat{x}_{\backslash M})LMLM​=−i∈M∑​logP(xi​∣x^\M​)

其中 MMM 为掩码位置集合，x^\M\hat{x}_{\backslash M}x^\M​ 为除掩码位置外的输入。

# 下一句预测与句子顺序预测

虽然 BERT 最初使用下一句预测 (Next Sentence Prediction, NSP)，但后续研究表明该策略效果有限。更有效的替代方案是句子顺序预测 (Sentence Order Prediction, SOP)，通过判断两个句子的正确顺序来学习句间关系。

BERT 使用特殊标记 [CLS] 和 [SEP] 来标识句子边界，其中 [CLS] 的输出向量常用于句子级别的分类任务。

# 预训练与微调范式

自监督学习模型的训练分为两个阶段：

  1. 预训练 (Pre-training): 在大规模无标注数据上进行自监督学习
  2. 微调 (Fine-tuning): 在特定下游任务的标注数据上进行有监督学习

这种范式本质上是半监督学习 (semi-supervised learning)，因为它结合了无监督的预训练和有监督的微调过程。相比随机初始化，预训练参数为下游任务提供了更好的起始点。

BERT 的预训练需要大规模训练数据才能获得良好效果。训练数据的规模和质量直接影响模型的最终性能。

# 序列到序列预训练模型

MASS与BART模型对比

MASS (Masked Sequence to Sequence Pre-training) 是微软提出的序列到序列预训练方法，通过掩码连续片段并重构来训练编码器 - 解码器架构。

BART (Denoising Autoencoder for NLP) 是 Facebook 提出的去噪自编码器，结合了 BERT 和 GPT 的优势。BART 使用多种噪声函数（包括 token 掩码、token 删除、文本填充、句子排列、文档旋转）来破坏文本，然后学习重构原始文本。

相比 MASS，BART 的去噪策略更加多样化，在文本生成任务上表现更优。

# 多语言模型与跨语言迁移

多语言 BERT (multilingual BERT) 在多种语言的混合数据上进行预训练，能够实现跨语言知识迁移。

# 跨语言向量对齐

通过计算不同语言词嵌入的平均距离差，可以实现简单的跨语言迁移：

中文结果=英文结果+(vˉ中文−vˉ英文)\text{中文结果} = \text{英文结果} + (\bar{v}_{\text{中文}} - \bar{v}_{\text{英文}})中文结果=英文结果+(vˉ中文​−vˉ英文​)

其中 vˉ语言\bar{v}_{\text{语言}}vˉ语言​ 表示该语言词嵌入的平均向量。

多语言模型的资源需求

多语言模型的效果很大程度上取决于训练数据的规模。不同语言的数据量差异会导致模型在各语言上的性能不均衡。高资源语言通常获得更好的表示，而低资源语言可能需要额外的技术手段来改善效果。

# GPT 系列与生成式预训练

# 上下文学习能力

GPT 展现出强大的上下文学习 (in-context learning) 能力，能够在不进行梯度更新的情况下完成：

  • Zero-shot learning: 无示例学习
  • One-shot learning: 单示例学习
  • Few-shot learning: 少样本学习

这种能力使 GPT 能够通过提示工程 (prompt engineering) 来完成多种任务。

# 对比学习方法

SimCLR对比学习框架

SimCLR (Simple Framework for Contrastive Learning of Visual Representations) 是 Google 提出的视觉表示对比学习框架。核心思想是通过数据增强创建正样本对，然后在特征空间中拉近正样本对的距离，推远负样本对的距离。

损失函数为 InfoNCE：

LSimCLR=−log⁡exp⁡(sim(zi,zj)/τ)∑k=12N1k≠iexp⁡(sim(zi,zk)/τ)L_{SimCLR} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbf{1}_{k \neq i} \exp(\text{sim}(z_i, z_k)/\tau)}LSimCLR​=−log∑k=12N​1k=i​exp(sim(zi​,zk​)/τ)exp(sim(zi​,zj​)/τ)​

其中 zi,zjz_i, z_jzi​,zj​ 为正样本对的特征表示，τ\tauτ 为温度参数。

BYOL自举学习方法

BYOL (Bootstrap Your Own Latent) 是 DeepMind 提出的自监督学习方法，无需负样本即可学习有效表示。BYOL 使用两个神经网络：在线网络和目标网络。在线网络学习预测目标网络对同一图像不同增强版本的表示。

关键创新在于目标网络参数通过在线网络参数的指数移动平均更新：

θtarget←τθtarget+(1−τ)θonline\theta_{\text{target}} \leftarrow \tau \theta_{\text{target}} + (1-\tau) \theta_{\text{online}}θtarget​←τθtarget​+(1−τ)θonline​

这种设计避免了表示坍塌问题，无需显式的负样本对比。
